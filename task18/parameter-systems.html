🔢 Системы с параметром

📚 Особенности решения систем

Системы уравнений с параметром требуют одновременного выполнения всех уравнений системы. Параметр влияет на количество решений и их существование.

🔹 Основные методы:
• Графический: строим графики всех уравнений, ищем точки пересечения.
• Аналитический: решаем систему алгебраически, исследуем условия совместности.
• Метод областей: для систем неравенств строим области допустимых значений.
Рис. 1. Графическое решение системы: точки пересечения — решения системы

💡 Пример 1: Линейная система с параметром

Условие: Найдите все значения параметра a, при которых система имеет единственное решение:
$$\begin{cases} ax + y = 3 \\ x + ay = 3 \end{cases}$$

Рис. 2. Две прямые пересекаются в одной точке при большинстве значений a

Решение:

1. Система имеет единственное решение, когда прямые пересекаются (не параллельны и не совпадают).
2. Найдем определитель системы: Δ = a·a - 1·1 = a² - 1.
3. Для единственного решения нужно Δ ≠ 0: a² - 1 ≠ 0.
4. Решаем: a² ≠ 1 ⟹ a ≠ 1 и a ≠ -1.
5. При a = 1: обе прямые совпадают (x + y = 3). Бесконечно много решений.
6. При a = -1: прямые параллельны (-x + y = 3 и x - y = 3). Нет решений.
7. Ответ: при всех a, кроме ±1.
Ответ: a ∈ (-∞; -1) ∪ (-1; 1) ∪ (1; +∞)

💡 Пример 2: Система с окружностью и прямой

Условие: Найдите все значения a, при которых система имеет ровно два решения:
$$\begin{cases} x^2 + y^2 = 4 \\ y = ax + 1 \end{cases}$$

Рис. 3. Прямая пересекает окружность в двух точках

Решение:

1. Подставляем y = ax + 1 в первое уравнение: x² + (ax + 1)² = 4.
2. Раскрываем: x² + a²x² + 2ax + 1 = 4.
3. Приводим: (1 + a²)x² + 2ax - 3 = 0.
4. Это квадратное уравнение относительно x. Для двух решений нужно D > 0.
5. D = (2a)² - 4(1 + a²)(-3) = 4a² + 12(1 + a²) = 4a² + 12 + 12a² = 16a² + 12.
6. 16a² + 12 > 0 всегда верно при всех действительных a.
7. Значит, система всегда имеет два решения при любом a.
Ответ: a ∈ (-∞; +∞)

💡 Пример 3: Система с модулем (ЕГЭ)

Условие: Найдите все значения a, при которых система имеет ровно три решения:
$$\begin{cases} |x| + |y| = 2 \\ y = ax \end{cases}$$

Рис. 4. График |x| + |y| = 2 — ромб с вершинами (±2; 0), (0; ±2)

Решение:

1. График |x| + |y| = 2 — это ромб с вершинами в точках (2; 0), (-2; 0), (0; 2), (0; -2).
2. Прямая y = ax проходит через начало координат (0; 0).
3. Рассмотрим случаи:
Случай a = 0: Прямая y = 0 (ось x). Пересекает ромб в точках (2; 0) и (-2; 0). Решений: 2.
Случай a > 0: Прямая проходит через I и III четверти. Пересекает ромб в 2 точках.
Случай a < 0: Прямая проходит через II и IV четверти. Пересекает ромб в 2 точках.
4. Для трёх решений прямая должна проходить через вершину ромба и ещё две точки.
5. Это невозможно, так как прямая через начало координат может пересечь ромб максимум в 2 точках.
6. Пересчитаем: если прямая проходит через вершину (0; 2), то a не определено (вертикальная прямая).
7. На самом деле, три решения возможны, когда прямая проходит через вершину ромба и ещё две точки на сторонах.
8. Вершины: (2; 0), (-2; 0), (0; 2), (0; -2). Прямая y = ax проходит через (0; 0).
9. Если a = 1: y = x. Пересекает в (1; 1) и (-1; -1). Решений: 2.
10. Если a = -1: y = -x. Пересекает в (1; -1) и (-1; 1). Решений: 2.
11. Три решения невозможны для данной системы.
Ответ: таких a не существует

📝 Методы решения

Графический метод:
1. Построить графики всех уравнений системы.
2. Найти точки пересечения графиков.
3. Исследовать, как меняется количество пересечений при изменении параметра.
Аналитический метод:
1. Выразить одну переменную через другую из одного уравнения.
2. Подставить в другое уравнение.
3. Исследовать полученное уравнение на количество корней.
Метод областей (для неравенств):
1. Построить области, заданные каждым неравенством.
2. Найти пересечение областей.
3. Исследовать, при каких значениях параметра пересечение непусто.

🎯 Советы для ЕГЭ

  • Графический метод часто проще и нагляднее для систем с параметром.
  • Запоминайте стандартные графики: окружности, параболы, модули, гиперболы.
  • Для линейных систем используйте определитель: Δ ≠ 0 — единственное решение.
  • Проверяйте особые случаи: когда коэффициент при переменной равен нулю.
  • Для систем с окружностью и прямой исследуйте расстояние от центра до прямой.
  • Записывайте ответ в виде промежутков или объединения точек.
