📐 Координатная плоскость (x, a)

📚 Суть метода

Метод координатной плоскости (x, a) позволяет решать уравнения и неравенства с параметром геометрически. Вместо того чтобы искать x для каждого a, мы строим график уравнения на плоскости, где по горизонтали откладывается x, а по вертикали — a. Затем проводим горизонтальные прямые a = const и смотрим, как они пересекают график.

🔹 Алгоритм:
1. Выразить параметр a через x (если возможно): a = f(x).
2. Построить график функции a = f(x) на плоскости (x, a).
3. Проводить горизонтальные прямые a = const.
4. Считать количество точек пересечения — это и есть количество корней уравнения при данном a.
Рис. 1. На плоскости (x, a) горизонтальная прямая a = const пересекает график в точках-корнях

💡 Пример 1: Дробно-рациональная зависимость

Условие: Найдите все значения a, при которых уравнение a(x - 2) = x + 3 имеет корень, больший 4.

Рис. 2. График a = (x+3)/(x-2). Корень > 4 соответствует ветви гиперболы правее x=4

Решение:

1. Выразим a через x: a = (x + 3) / (x - 2).
2. Заметим, что x ≠ 2 (знаменатель не равен нулю). При a = 1 уравнение не имеет решений (1 = 1 + 5/(x-2) → 0=5).
3. Строим график функции a = 1 + 5/(x-2). Это гипербола с асимптотами x = 2 и a = 1.
4. Нас интересуют такие a, при которых график пересекает вертикальную полосу x > 4.
5. Найдём значение a в точке x = 4: a = (4+3)/(4-2) = 7/2 = 3.5.
6. При x → 2+ (справа от 2) a → +∞. При x → +∞ a → 1.
7. Значит, при x > 4 значения a лежат в интервале (1; 3.5).
Ответ: a ∈ (1; 3.5)

💡 Пример 2: Квадратное уравнение

Условие: Найдите все значения a, при которых уравнение x² + ax + 1 = 0 имеет ровно один корень.

Рис. 3. График a = -(x + 1/x). Касание горизонталей даёт единственный корень

Решение:

1. Выразим a: ax = -x² - 1 → a = -(x + 1/x). (x ≠ 0, так как при x=0 уравнение 1=0 неверно).
2. Исследуем функцию f(x) = -(x + 1/x). Она нечётная, значит график симметричен относительно начала координат.
3. Найдём экстремумы. Для x > 0: по неравенству Коши x + 1/x ≥ 2, значит f(x) ≤ -2. Минимум f(1) = -2.
4. Для x < 0: максимум f(-1) = 2.
5. Область значений функции: (-∞; -2] ∪ [2; +∞).
6. Горизонтальная прямая a = const пересекает график в одной точке только в точках касания (экстремумах).
7. Значит, ровно один корень при a = 2 или a = -2.
Ответ: a = ±2

💡 Пример 3: Уравнение с модулем (ЕГЭ)

Условие: Найдите все значения a, при которых уравнение |x - 1| + |x - 4| = a имеет ровно три решения.

Рис. 4. График a = |x-1| + |x-4|. На отрезке [1; 4] функция постоянна и равна 3

Решение:

1. Построим график функции f(x) = |x - 1| + |x - 4| на плоскости (x, a).
2. Раскроем модули по интервалам:
x < 1: f(x) = -(x-1) - (x-4) = -2x + 5 (убывает)
1 ≤ x ≤ 4: f(x) = (x-1) - (x-4) = 3 (постоянна)
x > 4: f(x) = (x-1) + (x-4) = 2x - 5 (возрастает)
3. График представляет собой "корыто": две наклонные лучи и горизонтальный отрезок на уровне a = 3 между x = 1 и x = 4.
4. Проводим горизонтальные прямые a = const:
a < 3: Прямая ниже "дна". Пересечений нет. Корней: 0.
a = 3: Прямая совпадает с дном. Пересекает график по всему отрезку [1; 4]. Корней: бесконечно много.
a > 3: Прямая выше дна. Пересекает левый и правый лучи ровно в одной точке каждый. Корней: 2.
5. Видим, что ни при каком a уравнение не имеет ровно три решения.
Ответ: таких a не существует

📝 Полезные факты

Когда применять метод (x, a):
• Уравнение линейно относительно параметра a (легко выразить a = f(x)).
• Нужно найти количество корней или их расположение в зависимости от a.
• Уравнение содержит модули, корни или дроби, которые сложно решать аналитически.
Интерпретация пересечений:
• 0 точек пересечения → уравнение не имеет корней при данном a.
• 1 точка → ровно один корень.
• 2 точки → два различных корня.
• Отрезок пересечения → бесконечно много корней (все x из отрезка).
Симметрия:
Если f(x) чётная, график симметричен относительно оси a. Это позволяет строить только правую ветвь (x ≥ 0) и отражать её.

🎯 Советы для ЕГЭ

  • Метод (x, a) особенно удобен, когда параметр входит в уравнение линейно. Всегда пробуйте выразить a через x.
  • Не забывайте про ОДЗ! Точки, где знаменатель обращается в ноль или подкоренное выражение отрицательно, выкалываются на графике.
  • При построении графика ищите асимптоты, экстремумы и точки излома (для модулей).
  • Если в условии сказано "ровно три корня", а график имеет "корыто", проверьте, не касается ли прямая вершин или не проходит ли через стыки кусков.
  • Всегда подписывайте оси x и a на чертеже, чтобы не запутаться при анализе.
