🧮 Аналитическое решение уравнений и неравенств

📚 Суть метода

Аналитический метод решения задач с параметром — это алгебраическое преобразование уравнений и неравенств без построения графиков. Мы работаем непосредственно с формулами, используя дискриминант, теорему Виета и метод интервалов.

🔹 Ключевые инструменты:
• Дискриминант (D): определяет количество корней квадратного уравнения.
• Теорема Виета: связывает корни и коэффициенты.
• ОДЗ: ограничения на переменную (знаменатель ≠ 0, подкоренное выражение ≥ 0).
Рис. 1. Разбиение числовой прямой на интервалы по критическим точкам параметра

💡 Пример 1: Квадратное уравнение и Дискриминант

Условие: Найдите все значения параметра a, при которых уравнение ax² + 4x + 1 = 0 имеет два различных корня.

Рис. 2. Дискриминант квадратного уравнения как функция от a

Решение:

1. Для квадратного уравнения ax² + bx + c = 0 дискриминант D = b² - 4ac.
2. В нашем случае: a = a, b = 4, c = 1. Значит, D = 4² - 4·a·1 = 16 - 4a.
3. Для двух различных корней нужно D > 0: 16 - 4a > 0.
4. Решаем неравенство: 16 > 4a ⟹ a < 4.
5. Но также нужно, чтобы уравнение было квадратным, то есть a ≠ 0.
6. Ответ: a ∈ (-∞; 0) ∪ (0; 4).
Ответ: a ∈ (-∞; 0) ∪ (0; 4)

💡 Пример 2: Уравнение с ОДЗ

Условие: Найдите все значения a, при которых уравнение √(x - a) = x - 2 имеет единственный корень.

Рис. 3. График корня и прямой. Единственный корень при касании

Решение:

1. Возведем обе части в квадрат: x - a = (x - 2)².
2. Раскроем скобки: x - a = x² - 4x + 4.
3. Получим квадратное уравнение: x² - 5x + (4 + a) = 0.
4. Для единственного корня исходного уравнения нужно, чтобы это квадратное уравнение имело единственный корень, удовлетворяющий ОДЗ.
5. ОДЗ: x - a ≥ 0 и x - 2 ≥ 0 ⟹ x ≥ 2.
6. Дискриминант D = (-5)² - 4·1·(4 + a) = 25 - 16 - 4a = 9 - 4a.
7. При D = 0: 9 - 4a = 0 ⟹ a = 2.25. Корень x = 5/2 = 2.5. Проверяем ОДЗ: 2.5 ≥ 2 — верно.
8. При D > 0 есть два корня. Нужно проверить, попадает ли только один из них в ОДЗ.
9. Если a < 2.25, то D > 0. Корни: x = (5 ± √(9-4a))/2.
10. Меньший корень x₁ должен быть < 2, а больший x₂ ≥ 2.
11. Условие f(2) ≤ 0 для параболы y = x² - 5x + 4 + a: 4 - 10 + 4 + a ≤ 0 ⟹ a - 2 ≤ 0 ⟹ a ≤ 2.
12. Итог: a = 2.25 или a ≤ 2.
Ответ: a ∈ (-∞; 2] ∪ {2.25}

💡 Пример 3: Дробно-рациональное неравенство (ЕГЭ)

Условие: Найдите все значения a, при которых неравенство (x - a)/(x² - 4) ≥ 0 имеет решение.

Рис. 4. Расстановка знаков методом интервалов

Решение:

1. Найдем нули числителя и знаменателя. Числитель: x = a. Знаменатель: x = ±2.
2. Эти точки разбивают числовую прямую на интервалы. Нам нужно, чтобы хотя бы на одном интервале функция была положительной (или равна нулю).
3. Знаменатель x² - 4 положителен при |x| > 2 и отрицателен при |x| < 2.
4. Рассмотрим случаи расположения точки a относительно -2 и 2.
Случай 1: a > 2.
На интервале (2; a) числитель отрицателен, знаменатель положителен. Дробь отрицательна.
На интервале (a; +∞) числитель положителен, знаменатель положителен. Дробь положительна. Решение есть. ✓
Случай 2: -2 < a < 2.
На интервале (a; 2) числитель положителен, знаменатель отрицателен. Дробь отрицательна.
На интервале (2; +∞) числитель положителен, знаменатель положителен. Дробь положительна. Решение есть. ✓
Случай 3: a < -2.
На интервале (-∞; -2) числитель отрицателен, знаменатель положителен. Дробь отрицательна.
На интервале (-2; a) числитель отрицателен, знаменатель отрицателен. Дробь положительна. Решение есть. ✓
5. Получается, решение есть почти всегда. Но есть нюанс: если a = 2 или a = -2, то числитель обращается в ноль в точке разрыва, что недопустимо. Но неравенство нестрогое (≥ 0), значит x=a — корень. Если a=2, то x=2 не входит в ОДЗ. Значит a ≠ ±2.
6. Однако, даже если a=2, на интервале (2; +∞) дробь положительна. Значит решение всё равно есть.
7. Единственный случай, когда решения нет — это если дробь тождественно отрицательна. Но так как старшие коэффициенты положительны, на +∞ дробь всегда положительна.
8. Вывод: решение существует при любом a.
Ответ: a ∈ (-∞; +∞)

📝 Полезные факты

Квадратное уравнение ax² + bx + c = 0:
• D > 0: два различных корня
• D = 0: один корень (два равных)
• D < 0: нет действительных корней
Метод интервалов:
1. Найти нули числителя и знаменателя.
2. Отметить их на числовой прямой (нуль знаменателя — выколотая точка).
3. Определить знак функции на самом правом интервале.
4. Двигаться влево, меняя знак при переходе через точку нечетной кратности.
ОДЗ для корней:
√f(x) существует ⇔ f(x) ≥ 0
1/√f(x) существует ⇔ f(x) > 0

🎯 Советы для ЕГЭ

  • Всегда начинайте с нахождения ОДЗ — это отсеет лишние корни.
  • При возведении в квадрат проверяйте знаки обеих частей уравнения.
  • Для квадратных уравнений с параметром не забывайте случай a = 0 (уравнение становится линейным).
  • Метод интервалов — мощный инструмент. Тренируйтесь правильно расставлять знаки.
  • Если в ответе получается объединение промежутков и точек, записывайте аккуратно.
