🔢 Уравнения с параметром

📚 Основные подходы

В задании 18 встречаются уравнения с параметром. Параметр — это буква, которая обозначает некоторое число. Наша задача — найти, при каких значениях параметра уравнение имеет нужное количество корней.

🔹 Основные методы:
• Аналитический: решаем уравнение алгебраически, исследуем дискриминант, ОДЗ.
• Графический: строим графики функций, смотрим на точки пересечения.
• Метод областей: для систем уравнений с параметром.
Рис. 1. Как параметр влияет на количество корней уравнения

💡 Пример 1: Квадратное уравнение с параметром

Условие: Найдите все значения параметра a, при которых уравнение ax² + 2x + 1 = 0 имеет два различных корня.

Рис. 2. Дискриминант квадратного уравнения как функция от a

Решение:

1. Для квадратного уравнения ax² + bx + c = 0 дискриминант D = b² - 4ac.
2. В нашем случае: a = a, b = 2, c = 1. Значит, D = 2² - 4·a·1 = 4 - 4a.
3. Для двух различных корней нужно D > 0: 4 - 4a > 0.
4. Решаем неравенство: 4 > 4a ⟹ a < 1.
5. Но также нужно, чтобы уравнение было квадратным, то есть a ≠ 0.
6. Ответ: a ∈ (-∞; 0) ∪ (0; 1).
Ответ: a ∈ (-∞; 0) ∪ (0; 1)

💡 Пример 2: Уравнение с модулем и параметром

Условие: Найдите все значения a, при которых уравнение |x - 2| = a имеет ровно один корень.

Рис. 3. График y = |x - 2| и прямые y = a

Решение:

1. Построим график функции y = |x - 2|. Это «галочка» с вершиной в точке (2; 0).
2. Уравнение |x - 2| = a означает, что мы ищем точки пересечения графика с прямой y = a.
3. Рассмотрим случаи:
Случай a < 0: Прямая y = a лежит ниже оси x. Пересечений нет. Корней: 0.
Случай a = 0: Прямая y = 0 касается графика в вершине (2; 0). Корень: x = 2. Корней: 1. ✓
Случай a > 0: Прямая y = a пересекает график в двух точках. Корней: 2.
4. Нам нужно ровно один корень. Это происходит только при a = 0.
Ответ: a = 0

💡 Пример 3: Уравнение с параметром (ЕГЭ)

Условие: Найдите все значения a, при которых уравнение x² - 2ax + a² - 1 = 0 имеет корни разных знаков.

Рис. 4. Парабола с корнями разных знаков

Решение:

1. Для квадратного уравнения ax² + bx + c = 0 корни разных знаков тогда и только тогда, когда их произведение отрицательно.
2. По теореме Виета: x₁ · x₂ = c/a (где a — коэффициент при x², c — свободный член).
3. В нашем уравнении: коэффициент при x² равен 1, свободный член равен a² - 1.
4. Значит, x₁ · x₂ = a² - 1.
5. Для корней разных знаков нужно: a² - 1 < 0.
6. Решаем: a² < 1 ⟹ -1 < a < 1.
7. Проверим дискриминант: D = (-2a)² - 4·1·(a² - 1) = 4a² - 4a² + 4 = 4 > 0 всегда.
8. Значит, при всех a ∈ (-1; 1) уравнение имеет два корня разных знаков.
Ответ: a ∈ (-1; 1)

📝 Полезные факты

Квадратное уравнение ax² + bx + c = 0:
• D > 0: два различных корня
• D = 0: один корень (два равных)
• D < 0: нет действительных корней
• Корни разных знаков ⟺ c/a < 0
• Оба корня положительны ⟺ D ≥ 0, -b/a > 0, c/a > 0
Уравнение с модулем |x - a| = b:
• b < 0: нет решений
• b = 0: одно решение x = a
• b > 0: два решения x = a ± b
Уравнение √f(x) = a:
• a < 0: нет решений
• a ≥ 0: f(x) = a², при условии f(x) ≥ 0

🎯 Советы для ЕГЭ

  • Всегда проверяйте ОДЗ (область допустимых значений), особенно для уравнений с корнями и дробями.
  • Для квадратных уравнений с параметром исследуйте дискриминант и теорему Виета.
  • Графический метод часто проще аналитического — стройте графики!
  • Разбивайте задачу на случаи в зависимости от значения параметра.
  • Не забывайте проверять вырожденные случаи (когда коэффициент при x² равен 0).
  • Записывайте ответ в виде промежутков или объединения точек и промежутков.
