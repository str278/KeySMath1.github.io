📊 Функции, зависящие от параметра

📚 Основные понятия

Функция, зависящая от параметра — это функция вида y = f(x, a), где a — параметр.

При изменении параметра a:

  • Меняется вид графика функции
  • Меняются свойства функции (область определения, множество значений, монотонность)
  • Меняется количество корней уравнения f(x, a) = 0
\text{Например: } y = ax^2 + bx + c \text{ — семейство парабол, зависящее от } a

🎯 Типы задач с функциями от параметра

Тип 1: Исследование количества корней

Задача: Найти все значения параметра a, при которых уравнение f(x, a) = 0 имеет:

  • Ровно n корней
  • Хотя бы один корень
  • Не имеет корней
  • Бесконечно много корней
Тип 2: Исследование свойств функции

Задача: Найти все значения параметра a, при которых функция:

  • Возрастает/убывает на заданном промежутке
  • Имеет экстремумы
  • Принимает определённые значения
Тип 3: Графические задачи

Задача: Построить график функции y = f(x, a) и исследовать его поведение при различных a.

📝 Примеры решения

Пример 1. Квадратичная функция с параметром

Найдите все значения параметра a, при которых функция

f(x) = ax² + 2x + 1

имеет ровно один корень.

Решение:
1. Рассмотрим случай a = 0:
f(x) = 2x + 1 = 0 \Leftrightarrow x = -\frac{1}{2}

Один корень — подходит.

2. Рассмотрим случай a ≠ 0 (квадратичная функция):

Квадратное уравнение имеет ровно один корень, когда дискриминант равен нулю:

D = 4 - 4a = 0 \Leftrightarrow 4a = 4 \Leftrightarrow a = 1

Проверка: при a = 1: x² + 2x + 1 = (x+1)² = 0 ⇔ x = -1 (один корень)

Ответ: a = 0 или a = 1

Пример 2. Дробно-рациональная функция

Найдите все значения параметра a, при которых уравнение

\frac{x - a}{x - 2} = 1

имеет решения.

Решение:
1. ОДЗ:
x - 2 \neq 0 \Leftrightarrow x \neq 2
2. Решим уравнение:
\frac{x - a}{x - 2} = 1
x - a = x - 2
-a = -2 \Leftrightarrow a = 2
3. Анализ:

При a = 2 получаем тождество 0 = 0, но это не даёт конкретных x.

При a ≠ 2 уравнение не имеет решений (получаем противоречие).

Ответ: таких значений a не существует

Пример 3. Показательная функция с параметром

Найдите все значения параметра a, при которых уравнение

a \cdot 2^x = 4^x - 3

имеет хотя бы один корень.

Решение:
1. Замена переменной:

Пусть t = 2^x, где t > 0. Тогда 4^x = (2²)^x = 2^(2x) = t²

at = t² - 3
t² - at - 3 = 0
2. Исследуем квадратное уравнение:
D = a² + 12 > 0 \text{ при всех } a

Значит, уравнение всегда имеет два различных корня:

t_{1,2} = \frac{a \pm \sqrt{a² + 12}}{2}
3. Условие t > 0:

t₁ = (a + √(a²+12))/2:

a + \sqrt{a²+12} > 0 \Leftrightarrow \sqrt{a²+12} > -a

При a ≥ 0: очевидно верно

При a < 0: √(a²+12) > |a| ⇔ a² + 12 > a² ⇔ 12 > 0 — верно

Значит, t₁ > 0 при всех a.

Ответ: при всех a ∈ (-∞; +∞) уравнение имеет хотя бы один корень

Пример 4. Функция с модулем и параметром

Найдите все значения параметра a, при которых функция

f(x) = |x - a| + |x + a|

принимает наименьшее значение, равное 4.

Решение:
1. Геометрический смысл:

|x - a| — расстояние от точки x до точки a

|x + a| = |x - (-a)| — расстояние от точки x до точки -a

f(x) — сумма расстояний от x до точек a и -a

2. Рассмотрим случаи:

Случай a = 0:

f(x) = |x| + |x| = 2|x|

Наименьшее значение: f(0) = 0 ≠ 4 — не подходит

Случай a > 0: Критические точки: -a и a

  • При x < -a: f(x) = -(x-a) - (x+a) = -2x
  • При -a ≤ x ≤ a: f(x) = -(x-a) + (x+a) = 2a
  • При x > a: f(x) = (x-a) + (x+a) = 2x

Наименьшее значение: f_min = 2a (на промежутке [-a; a])

2a = 4 \Leftrightarrow a = 2

Случай a < 0: Пусть a = -b, где b > 0

Получаем тот же случай, что и при a > 0: f_min = 2|a|

2|a| = 4 \Leftrightarrow |a| = 2 \Leftrightarrow a = \pm 2

Ответ: a = 2 или a = -2

💡 Графический метод:
Часто удобно строить графики функций y = f(x, a) при различных значениях параметра и анализировать их пересечение с прямой y = 0 или другими линиями.

🔍 Основные приёмы исследования

Приём 1: Метод интервалов для параметра
  1. Найти критические значения параметра (где меняется поведение функции)
  2. Разбить числовую прямую a на интервалы
  3. Исследовать функцию на каждом интервале
Приём 2: Замена переменной

Применяется, когда функция содержит:

  • Показательные выражения: t = a^x
  • Логарифмы: t = log_a(x)
  • Тригонометрические функции: t = sin(x) или t = cos(x)
Приём 3: Использование свойств функций
  • Монотонность: если функция возрастает/убывает, то уравнение f(x) = c имеет не более одного корня
  • Непрерывность: если функция непрерывна и меняет знак, то по теореме Больцано-Коши имеет корень
  • Ограниченность: помогает найти множество значений функции
⚠️ Типичные ошибки:
• Не рассматривают все случаи для параметра
• Забывают проверить ОДЗ
• Не учитывают вырожденные случаи (коэффициент при старшей степени = 0)
• Ошибки при исследовании знака дискриминанта
• Не проверяют принадлежность корней области определения

📋 Что важно помнить для ЕГЭ

  • Всегда рассматривайте все возможные случаи для параметра
  • Используйте графическую интерпретацию для проверки
  • Проверяйте вырожденные случаи (коэффициенты = 0)
  • Замена переменной часто упрощает решение
  • Геометрический смысл модуля помогает в решении
  • Исследуйте поведение функции на границах интервалов
