📐 Уравнения с параметром, содержащие модуль

📚 Основные понятия

Модуль числа |a| — это расстояние от точки a до начала координат на числовой прямой.

|a| = \begin{cases} a, & \text{если } a \geq 0 \\ -a, & \text{если } a < 0 \end{cases}

При решении уравнений с параметром и модулем важно помнить:

  • Модуль всегда неотрицателен: |f(x)| ≥ 0
  • |a| = |b| ⇔ a = b или a = -b
  • |f(x)| = a ⇔ система: f(x) = a или f(x) = -a (при a ≥ 0)

🎯 Основные типы уравнений

Тип 1: Уравнение вида |f(x)| = g(a)

Схема решения:

  1. Рассмотреть случай g(a) < 0 — решений нет
  2. Рассмотреть случай g(a) ≥ 0 — решить совокупность:
    f(x) = g(a) или f(x) = -g(a)
Тип 2: Уравнение вида |f(x)| = |g(x)|

Схема решения:

|f(x)| = |g(x)| ⇔ f(x) = g(x) или f(x) = -g(x)
Тип 3: Уравнение вида |f(x, a)| = g(x, a)

Схема решения:

|f(x,a)| = g(x,a) ⇔ \begin{cases} g(x,a) \geq 0 \\ f(x,a) = g(x,a) \text{ или } f(x,a) = -g(x,a) \end{cases}

📝 Примеры решения

Пример 1. Найдите все значения параметра a, при которых уравнение имеет решения
|x - 2| = a - 1
Решение:
1. Левая часть |x - 2| ≥ 0 при всех x
2. Значит, правая часть тоже должна быть неотрицательной:
a - 1 ≥ 0 ⇔ a ≥ 1
3. При a ≥ 1 уравнение равносильно совокупности:
\begin{cases} x - 2 = a - 1 \\ x - 2 = -(a - 1) \end{cases} ⇔ \begin{cases} x = a + 1 \\ x = 3 - a \end{cases}

Ответ: при a ≥ 1 уравнение имеет два корня: x₁ = a + 1, x₂ = 3 - a

при a < 1 — корней нет

Пример 2. При каких a уравнение имеет ровно один корень?
|x - a| + |x + a| = 2
Решение:
1. Рассмотрим различные случаи расположения x относительно точек a и -a
2. Случай a = 0:
|x| + |x| = 2 ⇔ 2|x| = 2 ⇔ |x| = 1 ⇔ x = ±1

Два корня — не подходит

3. Случай a > 0: Критические точки: -a и a

а) При x < -a: |x-a| = -(x-a), |x+a| = -(x+a)

-(x-a) - (x+a) = 2 ⇔ -2x = 2 ⇔ x = -1

Условие: -1 < -a ⇔ a < 1

б) При -a ≤ x ≤ a: |x-a| = -(x-a), |x+a| = x+a

-(x-a) + (x+a) = 2 ⇔ 2a = 2 ⇔ a = 1

При a = 1: любое x ∈ [-1; 1] — бесконечно много корней

в) При x > a: |x-a| = x-a, |x+a| = x+a

(x-a) + (x+a) = 2 ⇔ 2x = 2 ⇔ x = 1

Условие: 1 > a ⇔ a < 1

4. Вывод: При 0 < a < 1 имеем два корня: x = -1 и x = 1

При a = 1 — бесконечно много корней

При a > 1 — корней нет

Ответ: таких значений a не существует

💡 Важный приём:
При решении уравнений с модулем и параметром часто полезно:
• Использовать геометрический смысл модуля (расстояние)
• Строить графики функций y = |f(x, a)| и y = g(x, a)
• Рассматривать различные случаи знака подмодульных выражений
• Использовать метод интервалов

🔍 Метод интервалов для уравнений с модулем

Алгоритм решения:
  1. Найти все точки, где подмодульные выражения равны нулю
  2. Отметить эти точки на числовой прямой
  3. Разбить прямую на интервалы
  4. На каждом интервале раскрыть модули с соответствующим знаком
  5. Решить уравнение на каждом интервале
  6. Проверить принадлежность найденных корней интервалу

📋 Типовые задания ЕГЭ

На экзамене часто встречаются задачи типа:

  • «Найдите все a, при которых уравнение имеет ровно n корней»
  • «Найдите все a, при которых уравнение не имеет решений»
  • «Найдите все a, при которых уравнение имеет бесконечно много решений»
  • «Найдите все a, при которых корни удовлетворяют определённому условию»
⚠️ Типичные ошибки:
• Забывают проверить условие неотрицательности правой части
• Не рассматривают все возможные случаи
• Не проверяют принадлежность корней интервалам
• Ошибки при раскрытии модуля со знаком «минус»
