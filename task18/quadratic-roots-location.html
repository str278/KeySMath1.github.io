📊 Расположение корней квадратного трехчлена

📚 Основные условия

В задачах с параметром часто требуется найти значения параметра, при которых корни квадратного уравнения удовлетворяют определённым условиям расположения на числовой прямой.

🔹 Общие условия для квадратного уравнения ax² + bx + c = 0:
• D ≥ 0 (существование действительных корней)
• x₀ = -b/(2a) — абсцисса вершины параболы
• f(x₀) — значение функции в вершине
Рис. 1. Расположение корней квадратного трехчлена на числовой прямой

💡 Пример 1: Оба корня больше заданного числа

Условие: Найдите все значения a, при которых оба корня уравнения x² - 2ax + a² - 1 = 0 больше 2.

Рис. 2. Оба корня больше числа 2

Решение:

1. Для того чтобы оба корня были больше 2, должны выполняться три условия:
2. Условие 1: D ≥ 0. D = (-2a)² - 4·1·(a² - 1) = 4a² - 4a² + 4 = 4 > 0. Всегда верно.
3. Условие 2: Вершина параболы x₀ > 2. x₀ = -(-2a)/(2·1) = a. Значит, a > 2.
4. Условие 3: f(2) > 0 (значение функции в точке x = 2 положительно).
5. f(2) = 2² - 2a·2 + a² - 1 = 4 - 4a + a² - 1 = a² - 4a + 3.
6. Решаем неравенство: a² - 4a + 3 > 0. Корни: a = 1 и a = 3.
7. Методом интервалов: a ∈ (-∞; 1) ∪ (3; +∞).
8. Пересекаем с условием a > 2: получаем a ∈ (3; +∞).
Ответ: a ∈ (3; +∞)

💡 Пример 2: Корни разных знаков

Условие: Найдите все значения a, при которых уравнение x² + (a-1)x - a = 0 имеет корни разных знаков.

Рис. 3. Корни квадратного уравнения разных знаков

Решение:

1. Для корней разных знаков необходимо и достаточно, чтобы их произведение было отрицательным.
2. По теореме Виета: x₁ · x₂ = c/a = -a/1 = -a.
3. Условие: x₁ · x₂ < 0 ⟹ -a < 0 ⟹ a > 0.
4. Проверим дискриминант: D = (a-1)² - 4·1·(-a) = a² - 2a + 1 + 4a = a² + 2a + 1 = (a+1)² ≥ 0.
5. Дискриминант всегда неотрицателен, значит, корни всегда существуют.
6. Ответ: при всех a > 0 уравнение имеет корни разных знаков.
Ответ: a ∈ (0; +∞)

💡 Пример 3: Оба корня в заданном интервале (ЕГЭ)

Условие: Найдите все значения a, при которых оба корня уравнения x² - 4x + a = 0 принадлежат интервалу (0; 3).

Рис. 4. Оба корня принадлежат интервалу (0; 3)

Решение:

1. Для того чтобы оба корня принадлежали интервалу (0; 3), должны выполняться условия:
2. Условие 1: D ≥ 0. D = (-4)² - 4·1·a = 16 - 4a ≥ 0 ⟹ a ≤ 4.
3. Условие 2: Вершина x₀ ∈ (0; 3). x₀ = -(-4)/(2·1) = 2. 0 < 2 < 3 — верно.
4. Условие 3: f(0) > 0. f(0) = 0² - 4·0 + a = a > 0.
5. Условие 4: f(3) > 0. f(3) = 3² - 4·3 + a = 9 - 12 + a = a - 3 > 0 ⟹ a > 3.
6. Пересекаем все условия: a ≤ 4, a > 0, a > 3.
7. Получаем: a ∈ (3; 4].
Ответ: a ∈ (3; 4]

📝 Основные условия расположения корней

Оба корня больше α:
1. D ≥ 0
2. x₀ > α (вершина правее α)
3. f(α) > 0 (функция положительна в точке α)
Оба корня меньше α:
1. D ≥ 0
2. x₀ < α (вершина левее α)
3. f(α) > 0 (функция положительна в точке α)
Оба корня в интервале (α; β):
1. D ≥ 0
2. α < x₀ < β (вершина внутри интервала)
3. f(α) > 0 и f(β) > 0
Корни разных знаков:
1. D > 0
2. x₁ · x₂ < 0 ⟺ c/a < 0
Один корень больше α, другой меньше α:
1. D > 0
2. f(α) < 0 (функция отрицательна в точке α)

🎯 Советы для ЕГЭ

  • Всегда начинайте с условия D ≥ 0 (существование корней).
  • Запоминайте три основных условия: дискриминант, положение вершины, значение функции на границе.
  • Используйте теорему Виета для проверки знаков корней (произведение и сумма).
  • Рисуйте эскиз параболы — это помогает понять, какие условия нужны.
  • Не забывайте пересекать все полученные условия в конце решения.
  • Проверяйте граничные значения параметра — они часто входят в ответ.
