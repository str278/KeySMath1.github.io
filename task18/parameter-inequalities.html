🔢 Неравенства с параметром

📚 Особенности решения

Неравенства с параметром требуют особого внимания к знакам и области допустимых значений. При умножении или делении на выражение с параметром нужно учитывать его знак.

🔹 Важные правила:
• При умножении неравенства на отрицательное число знак неравенства меняется на противоположный.
• При возведении в чётную степень нужно проверять ОДЗ.
• Метод интервалов — основной инструмент для решения неравенств с параметром.
Рис. 1. Разбиение числовой прямой на интервалы по критическим точкам параметра

💡 Пример 1: Линейное неравенство с параметром

Условие: Найдите все значения параметра a, при которых неравенство ax > 2 имеет решения.

Рис. 2. Решения неравенства ax > 2 при разных значениях a

Решение:

1. Рассмотрим случаи в зависимости от знака параметра a.
Случай a > 0: Делим на положительное число, знак не меняется: x > 2/a. Решения есть. ✓
Случай a < 0: Делим на отрицательное число, знак меняется: x < 2/a. Решения есть. ✓
Случай a = 0: Неравенство принимает вид 0·x > 2, то есть 0 > 2. Это неверно. Решений нет. ✗
2. Ответ: неравенство имеет решения при всех a ≠ 0.
Ответ: a ∈ (-∞; 0) ∪ (0; +∞)

💡 Пример 2: Квадратное неравенство с параметром

Условие: Найдите все значения a, при которых неравенство x² - 2ax + a² - 1 < 0 выполняется для всех x ∈ (0; 2).

Рис. 3. Квадратичная функция должна быть отрицательна на интервале (0; 2)

Решение:

1. Преобразуем выражение: x² - 2ax + a² - 1 = (x - a)² - 1.
2. Неравенство принимает вид: (x - a)² - 1 < 0, то есть (x - a)² < 1.
3. Это равносильно: -1 < x - a < 1, откуда a - 1 < x < a + 1.
4. Нам нужно, чтобы интервал (0; 2) содержался в интервале (a-1; a+1).
5. Условия: a - 1 ≤ 0 и a + 1 ≥ 2.
6. Из первого: a ≤ 1. Из второго: a ≥ 1.
7. Значит, a = 1.
8. Проверка: при a = 1 получаем (x - 1)² < 1, то есть 0 < x < 2. Интервал (0; 2) подходит.
Ответ: a = 1

💡 Пример 3: Неравенство с модулем (ЕГЭ)

Условие: Найдите все значения a, при которых неравенство |x - a| + |x + a| ≤ 4 имеет хотя бы одно решение.

Рис. 4. График функции f(x) = |x-a| + |x+a| имеет минимум в точке x = 0

Решение:

1. Рассмотрим функцию f(x) = |x - a| + |x + a|.
2. Найдём минимум этой функции. При x = 0: f(0) = |-a| + |a| = 2|a|.
3. При x → ±∞ функция неограниченно возрастает.
4. Неравенство f(x) ≤ 4 имеет решения тогда и только тогда, когда минимум функции не превосходит 4.
5. Условие: 2|a| ≤ 4.
6. Решаем: |a| ≤ 2, то есть -2 ≤ a ≤ 2.
7. При таких a неравенство имеет бесконечно много решений (целый отрезок).
Ответ: a ∈ [-2; 2]

📝 Методы решения

Метод интервалов:
1. Найти критические точки (где выражение равно 0 или не определено).
2. Разбить числовую прямую на интервалы.
3. Определить знак выражения на каждом интервале.
4. Выбрать нужные интервалы в зависимости от знака неравенства.
Графический метод:
Построить график функции и найти, при каких значениях параметра график удовлетворяет условию неравенства.
Метод оценки:
Найти минимум или максимум функции и сравнить с правой частью неравенства.

🎯 Советы для ЕГЭ

  • Всегда разбирайте случаи для параметра (положительный, отрицательный, ноль).
  • При умножении/делении на выражение с параметром обязательно учитывайте его знак!
  • Используйте графическую интерпретацию — часто это проще аналитического решения.
  • Для квадратных неравенств исследуйте дискриминант и расположение корней.
  • Проверяйте граничные значения параметра — они часто дают важный ответ.
  • Записывайте ответ в виде промежутков или объединения точек и промежутков.
