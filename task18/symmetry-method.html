🔄 Использование симметрий

📚 Идея метода

Метод симметрий позволяет упростить решение уравнений и неравенств с параметром, используя симметричные свойства функций. Если функция симметрична относительно какой-либо точки или прямой, это можно использовать для нахождения решений.

🔹 Основные виды симметрии:
• Чётность: f(-x) = f(x) — симметрия относительно оси y.
• Нечётность: f(-x) = -f(x) — симметрия относительно начала координат.
• Симметрия относительно точки: f(a+x) + f(a-x) = 2b (симметрия относительно точки (a; b)).
• Периодичность: f(x+T) = f(x).
Рис. 1. Чётная функция симметрична относительно оси y

💡 Пример 1: Уравнение с чётной функцией

Условие: Найдите все значения a, при которых уравнение x⁴ - 2ax² + a² - 1 = 0 имеет ровно три различных корня.

Рис. 2. График чётной функции. Корни симметричны относительно оси y

Решение:

1. Заметим, что функция f(x) = x⁴ - 2ax² + a² - 1 чётная: f(-x) = f(x).
2. Это значит, что если x₀ — корень, то -x₀ тоже корень. Корни идут парами ±x₀.
3. Для того чтобы было ровно три корня, один из них должен быть x = 0 (он сам себе пара), а остальные два — пара ±x₀ (x₀ ≠ 0).
4. Подставляем x = 0: 0⁴ - 2a·0² + a² - 1 = 0 ⟹ a² - 1 = 0 ⟹ a = ±1.
5. Проверяем a = 1: x⁴ - 2x² + 1 - 1 = x⁴ - 2x² = x²(x² - 2) = 0.
6. Корни: x = 0 (кратность 2), x = ±√2. Всего три различных корня: 0, √2, -√2. ✓
7. Проверяем a = -1: x⁴ + 2x² + 1 - 1 = x⁴ + 2x² = x²(x² + 2) = 0.
8. Корни: x = 0 (кратность 2). Других действительных корней нет. Только один корень. ✗
Ответ: a = 1

💡 Пример 2: Симметрия относительно точки

Условие: Найдите все значения a, при которых уравнение (x - a)³ + (x - a) + 1 = 0 имеет ровно один корень.

Рис. 3. Кубическая функция симметрична относительно точки перегиба

Решение:

1. Сделаем замену t = x - a. Уравнение принимает вид: t³ + t + 1 = 0.
2. Рассмотрим функцию f(t) = t³ + t + 1.
3. Найдём производную: f'(t) = 3t² + 1.
4. f'(t) > 0 при всех t (так как 3t² ≥ 0 и 1 > 0).
5. Значит, функция f(t) строго возрастает на всей числовой прямой.
6. Строго возрастающая функция может пересекать ось x только в одной точке.
7. Проверяем пределы: при t → -∞, f(t) → -∞; при t → +∞, f(t) → +∞.
8. По теореме о промежуточном значении, существует ровно один корень.
9. Этот корень существует при любом a (так как замена t = x -a всегда возможна).
Ответ: a ∈ (-∞; +∞)

💡 Пример 3: Симметрия в системе (ЕГЭ)

Условие: Найдите все значения a, при которых система имеет решение:
$$\begin{cases} |x| + |y| = a \\ x^2 + y^2 = 4 \end{cases}$$

Рис. 4. Ромб и окружность симметричны относительно начала координат

Решение:

1. Обе функции симметричны относительно начала координат (чётные по x и y).
2 |x| + |y| = a — это ромб с вершинами (±a; 0), (0; ±a).
3. x² + y² = 4 — окружность радиуса 2 с центром в начале координат.
4. Система имеет решение, когда ромб и окружность пересекаются.
5. Минимальное значение a: когда ромб касается окружности изнутри. Это происходит при a = 2 (ромб вписан в окружность).
6. Максимальное значение: ромб может быть сколь угодно большим, но пересечение будет всегда при a ≥ 2.
7. Проверяем a = 2: |x| + |y| = 2 и x² + y² = 4. В точках (±2; 0), (0; ±2) оба уравнения выполняются.
8. При a < 2 ромб целиком внутри окружности, но не пересекает её (кроме случая a = 0, но тогда только (0; 0), что не лежит на окружности).
Ответ: a ∈ [2; +∞)

📝 Полезные факты

Симметрия чётной функции:
Если f(x) чётная и x₀ — корень, то -x₀ тоже корень.
Для нечётного количества корней один из них должен быть x = 0.
Симметрия относительно точки (a; b):
f(a+x) + f(a-x) = 2b
Если функция симметрична относительно точки, это можно использовать для упрощения.
Монотонность:
Если функция строго возрастает (или убывает) на всей области определения, то уравнение f(x) = c имеет не более одного корня.

🎯 Советы для ЕГЭ

  • Всегда проверяйте функцию на чётность/нечётность — это может сильно упростить задачу.
  • Если функция чётная, достаточно исследовать её на x ≥ 0, а потом отразить.
  • Используйте замену переменной для приведения функции к симметричному виду.
  • Монотонные функции имеют не более одного корня — это важный факт.
  • В системах уравнений ищите общую симметрию всех уравнений.
  • Графический метод часто помогает увидеть симметрию.
