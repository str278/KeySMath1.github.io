🧩 Аналитическое решение систем

📚 Суть аналитического подхода

Аналитическое решение систем с параметром — это алгебраическое сведение системы к одному уравнению или неравенству с последующим исследованием условий существования корней. Вместо построения графиков мы работаем напрямую с формулами, используя подстановку, сложение уравнений и теорему Виета.

🔹 Ключевые приёмы:
• Метод подстановки: выражаем одну переменную через другую и подставляем в оставшееся уравнение.
• Теорема Виета для систем: сумма и произведение корней квадратного уравнения помогают найти параметр без явного вычисления корней.
• Анализ вырожденных случаев: если коэффициент при старшей степени зависит от параметра, проверяем случай, когда он равен нулю.
Рис. 1. Схема аналитического сведения системы к исследованию одного уравнения

💡 Пример 1: Система и теорема Виета

Условие: Найдите все значения параметра a, при которых система имеет ровно два решения:
$$\begin{cases} x + y = a \\ xy = 1 \end{cases}$$

Рис. 2. Прямая пересекает гиперболу в двух точках при |a| > 2

Решение:

1. По теореме Виета, x и y являются корнями квадратного уравнения t² - (x+y)t + xy = 0.
2. Подставляем условия системы: t² - at + 1 = 0.
3. Система имеет два решения (x,y) и (y,x), если квадратное уравнение имеет два различных действительных корня.
4. Условие: D > 0. D = (-a)² - 4·1·1 = a² - 4.
5. a² - 4 > 0 ⟹ a² > 4 ⟹ |a| > 2.
6. Ответ: a ∈ (-∞; -2) ∪ (2; +∞).
Ответ: a ∈ (-∞; -2) ∪ (2; +∞)

💡 Пример 2: Подстановка и анализ ОДЗ

Условие: Найдите все значения a, при которых система имеет единственное решение:
$$\begin{cases} y = x^2 - 2x \\ y + x = a \end{cases}$$

Рис. 3. Касание параболы и прямой соответствует единственному решению

Решение:

1. Подставим y из первого уравнения во второе: (x² - 2x) + x = a.
2. Упрощаем: x² - x - a = 0.
3. Для единственного решения квадратного уравнения нужно D = 0.
4. D = (-1)² - 4·1·(-a) = 1 + 4a.
5. 1 + 4a = 0 ⟹ a = -0.25.
6. Проверяем ОДЗ: ограничений нет, x может быть любым.
7. При a = -0.25 уравнение имеет один корень x = 0.5, значит система имеет одно решение (0.5; -0.75).
Ответ: a = -0.25

💡 Пример 3: Система с вырожденным случаем (ЕГЭ)

Условие: Найдите все значения a, при которых система имеет бесконечно много решений:
$$\begin{cases} ax + y = 2 \\ 4x + ay = 8 \end{cases}$$

Рис. 4. Бесконечно много решений возникает при совпадении прямых

Решение:

1. Система линейных уравнений имеет бесконечно много решений, когда прямые совпадают.
2. Условие совпадения: коэффициенты пропорциональны, включая свободные члены.
3. Записываем пропорцию: a/4 = 1/a = 2/8.
4. Из 1/a = 2/8 получаем: 1/a = 1/4 ⟹ a = 4.
5. Проверяем первое отношение при a=4: 4/4 = 1. Всё сходится.
6. Но есть нюанс: если a=0, система становится {y=2, 4x=8}, что даёт одно решение (2;2). Не подходит.
7. Если a=-2, пропорция: -2/4 = -0.5, 1/(-2) = -0.5, но 2/8 = 0.25. Прямые параллельны, решений 0.
8. Единственное значение: a = 2. (Проверка: 2x+y=2 и 4x+2y=8 ⟺ 2x+y=4. Ошибка в пропорции! Пересчитаем.)
9. Верное условие: a/4 = 1/a = 2/8. Из 2/8=1/4. Значит a/4=1/4 ⟹ a=1. И 1/a=1/4 ⟹ a=4. Противоречие.
10. Исправим логику: Прямые совпадают, если уравнения эквивалентны. Умножим первое на 2: 2ax + 2y = 4. Чтобы совпало со вторым, нужно 2a=4 и 2=a. Значит a=2.
11. Проверка при a=2: {2x+y=2, 4x+2y=8} → {2x+y=2, 2x+y=4}. Параллельны! Решений нет.
12. Значит, бесконечно много решений невозможно. Ответ: таких a нет.
Ответ: таких a не существует

📝 Полезные факты

Линейная система {a₁x+b₁y=c₁, a₂x+b₂y=c₂}:
• Одно решение: a₁/a₂ ≠ b₁/b₂
• Нет решений: a₁/a₂ = b₁/b₂ ≠ c₁/c₂ (параллельные прямые)
• Бесконечно много: a₁/a₂ = b₁/b₂ = c₁/c₂ (совпадающие прямые)
Метод подстановки:
1. Выразить y через x из простого уравнения.
2. Подставить в сложное уравнение.
3. Исследовать полученное уравнение относительно x.
4. Найденные x подставить обратно для нахождения y.
Теорема Виета для систем:
Если x и y — корни t² - pt + q = 0, то x+y=p, xy=q.
Это позволяет находить параметр, не решая уравнение явно.

🎯 Советы для ЕГЭ

  • Всегда начинайте с попытки выразить одну переменную через другую — это самый надёжный путь.
  • Проверяйте случай, когда коэффициент при старшей степени обращается в ноль (вырожденный случай).
  • Для систем вида {x+y=S, xy=P} сразу используйте теорему Виета — это экономит время.
  • Не забывайте подставлять найденные корни обратно в систему для проверки ОДЗ.
  • Если в ответе получается "нет значений", перепроверьте пропорции и знаки — часто это ловушка.
