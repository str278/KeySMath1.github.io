🔍 Уравнения с параметром, содержащие радикалы

📚 Основные понятия

Иррациональное уравнение — это уравнение, содержащее переменную под знаком корня (радикала).

\sqrt{f(x)} = g(x)

Основные свойства арифметического квадратного корня:

  • √a определён только при a ≥ 0
  • √a ≥ 0 при всех допустимых a
  • (√a)² = a при a ≥ 0
  • √(a²) = |a|

🎯 Методы решения иррациональных уравнений с параметром

Метод 1: Возведение в квадрат

Схема решения уравнения √f(x) = g(x):

  1. Найти ОДЗ: f(x) ≥ 0 и g(x) ≥ 0
  2. Возвести обе части в квадрат: f(x) = [g(x)]²
  3. Решить полученное уравнение
  4. Проверить найденные корни на соответствие ОДЗ
⚠️ Важно: При возведении в чётную степень могут появиться посторонние корни! Обязательна проверка.
Метод 2: Замена переменной

Применяется, когда уравнение содержит несколько одинаковых радикалов или когда под корнем стоит сложное выражение.

\text{Например: } \sqrt{f(x)} = t, \text{ где } t \geq 0
Метод 3: Равенство одноимённых корней
\sqrt{f(x)} = \sqrt{g(x)} \Leftrightarrow \begin{cases} f(x) = g(x) \\ f(x) \geq 0 \\ g(x) \geq 0 \end{cases}

📝 Примеры решения

Пример 1. Найдите все значения параметра a, при которых уравнение имеет решения
\sqrt{x - a} = 2 - x
Решение:
1. Найдём ОДЗ:
\begin{cases} x - a \geq 0 \\ 2 - x \geq 0 \end{cases} \Leftrightarrow \begin{cases} x \geq a \\ x \leq 2 \end{cases} \Leftrightarrow a \leq x \leq 2

Значит, при a > 2 решений нет.

2. Возведём в квадрат (при a ≤ 2):
x - a = (2 - x)²
x - a = 4 - 4x + x²
x² - 5x + (4 + a) = 0
3. Найдём дискриминант:
D = 25 - 4(4 + a) = 25 - 16 - 4a = 9 - 4a
4. Рассмотрим случаи:

а) D < 0 ⇔ 9 - 4a < 0 ⇔ a > 9/4: корней нет

б) D = 0 ⇔ a = 9/4: один корень

x = \frac{5}{2} = 2.5

Проверка ОДЗ: 2.5 ≤ 2 — не выполняется. Значит, при a = 9/4 решений нет.

в) D > 0 ⇔ a < 9/4: два корня

x_{1,2} = \frac{5 \pm \sqrt{9 - 4a}}{2}
5. Проверка принадлежности корней промежутку [a; 2]:

Для x₁ = (5 + √(9-4a))/2:

\frac{5 + \sqrt{9-4a}}{2} \leq 2 \Leftrightarrow 5 + \sqrt{9-4a} \leq 4 \Leftrightarrow \sqrt{9-4a} \leq -1

Невозможно, так как √(9-4a) ≥ 0

Для x₂ = (5 - √(9-4a))/2:

\frac{5 - \sqrt{9-4a}}{2} \leq 2 \Leftrightarrow 5 - \sqrt{9-4a} \leq 4 \Leftrightarrow \sqrt{9-4a} \geq 1
9 - 4a \geq 1 \Leftrightarrow 4a \leq 8 \Leftrightarrow a \leq 2
6. Проверка условия x₂ ≥ a:
\frac{5 - \sqrt{9-4a}}{2} \geq a
5 - \sqrt{9-4a} \geq 2a
5 - 2a \geq \sqrt{9-4a}

При a ≤ 2: 5 - 2a ≥ 1 > 0, можно возводить в квадрат:

(5-2a)² \geq 9-4a
25 - 20a + 4a² \geq 9 - 4a
4a² - 16a + 16 \geq 0
a² - 4a + 4 \geq 0
(a-2)² \geq 0 \text{ — верно при всех } a

Ответ: при a ∈ (-∞; 2) уравнение имеет один корень x = (5 - √(9-4a))/2

при a ≥ 2 — решений нет

Пример 2. При каких a уравнение имеет ровно один корень?
\sqrt{x^2 - 4x + 3} = a
Решение:
1. ОДЗ:
a \geq 0
x² - 4x + 3 \geq 0
(x-1)(x-3) \geq 0

x ∈ (-∞; 1] ∪ [3; +∞)

2. Возведём в квадрат:
x² - 4x + 3 = a²
x² - 4x + (3 - a²) = 0
3. Дискриминант:
D = 16 - 4(3-a²) = 16 - 12 + 4a² = 4 + 4a² = 4(1+a²) > 0 \text{ при всех } a
4. Корни:
x_{1,2} = \frac{4 \pm 2\sqrt{1+a²}}{2} = 2 \pm \sqrt{1+a²}
5. Проверка принадлежности ОДЗ:

x₁ = 2 + √(1+a²):

2 + \sqrt{1+a²} \geq 3 \Leftrightarrow \sqrt{1+a²} \geq 1 \Leftrightarrow 1+a² \geq 1 \Leftrightarrow a² \geq 0

Верно при всех a. Значит, x₁ ∈ [3; +∞) — всегда подходит.

x₂ = 2 - √(1+a²):

2 - \sqrt{1+a²} \leq 1 \Leftrightarrow \sqrt{1+a²} \geq 1 \Leftrightarrow a² \geq 0

Верно при всех a. Значит, x₂ ∈ (-∞; 1] — всегда подходит.

6. Когда будет ровно один корень?

Когда x₁ = x₂:

2 + \sqrt{1+a²} = 2 - \sqrt{1+a²}
2\sqrt{1+a²} = 0 \Leftrightarrow \sqrt{1+a²} = 0 \Leftrightarrow 1+a² = 0

Невозможно при действительных a.

Ответ: таких значений a не существует (при всех a ≥ 0 уравнение имеет два корня)

💡 Важные замечания:
• Всегда проверяйте ОДЗ перед возведением в степень
• После возведения в квадрат обязательна проверка корней
• При a < 0 уравнение √f(x) = a не имеет решений
• Используйте графический метод для проверки количества корней

🔍 Типовые приёмы

Приём 1: Уравнения вида √f(x) + √g(x) = h(x)

Метод:

  1. Найти ОДЗ: f(x) ≥ 0, g(x) ≥ 0, h(x) ≥ 0
  2. Возвести в квадрат
  3. Сгруппировать слагаемые с радикалами
  4. Ещё раз возвести в квадрат (если нужно)
  5. Проверить все найденные корни
Приём 2: Уравнения вида √f(x) = √g(x)

Метод: сразу переходим к системе:

\begin{cases} f(x) = g(x) \\ f(x) \geq 0 \text{ (или } g(x) \geq 0) \end{cases}
⚠️ Типичные ошибки:
• Забывают проверить неотрицательность правой части
• Не проверяют корни после возведения в квадрат
• Ошибки при нахождении ОДЗ
• Теряют корни при сокращении
• Не рассматривают все случаи для параметра

📋 Что важно помнить для ЕГЭ

  • Арифметический квадратный корень всегда неотрицателен
  • При возведении в чётную степень расширяется область определения
  • Проверка корней — обязательный этап!
  • Иногда удобнее использовать замену переменной
  • Графический метод помогает понять количество корней
