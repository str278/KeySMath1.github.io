📐 Тригонометрические уравнения и неравенства

📚 Теория

Тригонометрическое уравнение — уравнение, содержащее тригонометрические функции от переменной. Тригонометрическое неравенство — неравенство вида sin x > a, cos x < a и т.д.

🔹 Основные функции:
sin x — синус
cos x — косинус
tan x — тангенс
cot x — котангенс
🔹 Основные методы решения:
  • Простейшие уравнения — по формулам
  • Замена переменной — сведение к алгебраическому
  • Разложение на множители — вынесение общего множителя
  • Однородные уравнения — деление на степень

📐 Основные формулы

1. Простейшие уравнения:
$$ \sin x = a \quad \Rightarrow \quad x = (-1)^n \arcsin a + \pi n $$ $$ \cos x = a \quad \Rightarrow \quad x = \pm \arccos a + 2\pi n $$ $$ \tan x = a \quad \Rightarrow \quad x = \arctan a + \pi n $$

где n ∈ Z

2. Частные случаи:
$$ \sin x = 0 \quad \Rightarrow \quad x = \pi n $$ $$ \cos x = 0 \quad \Rightarrow \quad x = \frac{\pi}{2} + \pi n $$ $$ \sin x = 1 \quad \Rightarrow \quad x = \frac{\pi}{2} + 2\pi n $$ $$ \cos x = 1 \quad \Rightarrow \quad x = 2\pi n $$

💡 Пример решения (ЕГЭ)

Условие: Решите уравнение: 2sin²x − 3sin x + 1 = 0

Решение:

1. Сделаем замену: sin x = t

2t² − 3t + 1 = 0

2. Решим квадратное уравнение:

D = 9 − 8 = 1
t₁ = (3 + 1)/4 = 1
t₂ = (3 − 1)/4 = 0.5

3. Вернёмся к переменной x:

sin x = 1 ⇒ x = π/2 + 2πn
sin x = 0.5 ⇒ x = (−1)ⁿ · π/6 + πn
Ответ: π/2 + 2πn; (−1)ⁿ · π/6 + πn, n ∈ Z
