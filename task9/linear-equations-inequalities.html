📐 Линейные уравнения и неравенства

📚 Теория

Линейное уравнение — уравнение вида ax + b = 0, где a ≠ 0. Линейное неравенство — неравенство вида ax + b > 0 (или <, ≥, ≤).

🔹 Обозначения:
a, b — коэффициенты
x — неизвестная переменная
ОДЗ — область допустимых значений
🔹 Основные свойства:
  • При переносе слагаемого через знак равенства/неравенства знак меняется на противоположный
  • При умножении/делении неравенства на отрицательное число знак неравенства меняется на противоположный
  • Линейное уравнение имеет один корень (при a ≠ 0)

График линейного уравнения

📐 Основные формулы

1. Решение линейного уравнения:
$$ ax + b = 0 \quad \Rightarrow \quad x = -\frac{b}{a} $$
2. Решение линейного неравенства (a > 0):
$$ ax + b > 0 \quad \Rightarrow \quad x > -\frac{b}{a} $$ $$ ax + b < 0 \quad \Rightarrow \quad x < -\frac{b}{a} $$
3. Решение линейного неравенства (a < 0):
$$ ax + b > 0 \quad \Rightarrow \quad x < -\frac{b}{a} $$ $$ ax + b < 0 \quad \Rightarrow \quad x > -\frac{b}{a} $$

💡 Пример решения (ЕГЭ)

Условие: Решите неравенство: 3(x − 2) − 2(x + 1) > 5

Решение:

1. Раскроем скобки:

3x − 6 − 2x − 2 > 5

2. Приведём подобные слагаемые:

x − 8 > 5

3. Перенесём −8 вправо:

x > 5 + 8
x > 13
Ответ: (13; +∞)
