📐 Рациональные уравнения и неравенства

📚 Теория

Рациональное уравнение — уравнение вида P(x)/Q(x) = 0. Рациональное неравенство — неравенство, содержащее рациональные выражения.

🔹 Обозначения:
P(x), Q(x) — многочлены
ОДЗ — Q(x) ≠ 0
Метод интервалов — основной метод
🔹 Алгоритм решения:
  • Перенести всё в одну сторону
  • Привести к общему знаменателю
  • Разложить на множители числитель и знаменатель
  • Применить метод интервалов
  • Учесть ОДЗ

📐 Основные формулы

1. Рациональное уравнение:
$$ \frac{P(x)}{Q(x)} = 0 \quad \Leftrightarrow \quad \begin{cases} P(x) = 0 \\ Q(x) \neq 0 \end{cases} $$
2. Метод интервалов для неравенств:
$$ \frac{(x-x_1)(x-x_2)...}{(x-a_1)(x-a_2)...} > 0 $$

Отмечаем все корни на числовой прямой и определяем знаки

💡 Пример решения (ЕГЭ)

Условие: Решите неравенство: (x − 2)/(x + 3) ≥ 0

Решение:

1. Найдём нули числителя и знаменателя:

x − 2 = 0 ⇒ x = 2
x + 3 = 0 ⇒ x = −3

2. Отметим на числовой прямой и определим знаки:

x ∈ (−∞; −3) — знак +
x ∈ (−3; 2) — знак −
x ∈ (2; +∞) — знак +

3. Выберем промежутки со знаком ≥ 0:

x ∈ (−∞; −3) ∪ [2; +∞)
Ответ: (−∞; −3) ∪ [2; +∞)
