📊 Задачи на оптимальный выбор

📚 Теория

Задачи на оптимальный выбор — задачи, в которых требуется найти наилучшее (оптимальное) решение по заданному критерию (минимум затрат, максимум прибыли и т.д.).

🔹 Типичные задачи:
  • Выбор наиболее выгодного тарифа
  • Оптимальное распределение ресурсов
  • Минимизация затрат или максимизация дохода
  • Выбор между различными вариантами инвестиций

📐 Основные методы

1. Метод сравнения:

Рассчитать итоговые значения для каждого варианта и выбрать оптимальный
2. Метод функции:

Составить функцию зависимости и найти её экстремум (минимум или максимум)

💡 Примеры решения (ЕГЭ)

Пример 1: Клиент хочет выбрать наиболее выгодный тариф мобильной связи. Тариф "Стандарт": 200 руб/мес + 1 руб/мин. Тариф "Премиум": 500 руб/мес + 0.5 руб/мин. При каком количестве минут тариф "Премиум" выгоднее?

Решение:

1. Обозначим количество минут за x

2. Стоимость тарифа "Стандарт":

C₁ = 200 + x

3. Стоимость тарифа "Премиум":

C₂ = 500 + 0.5x

4. Найдём, когда C₂ < C₁:

500 + 0.5x < 200 + x
300 < 0.5x
x > 600
Ответ: при более 600 минут в месяц

Пример 2: Фирма может произвести товар двумя способами. Способ 1: постоянные затраты 100 000 руб, себестоимость 500 руб/шт. Способ 2: постоянные затраты 200 000 руб, себестоимость 300 руб/шт. При каком объёме производства способ 2 выгоднее?

Решение:

1. Обозначим количество единиц товара за x

2. Затраты способом 1:

Z₁ = 100 000 + 500x

3. Затраты способом 2:

Z₂ = 200 000 + 300x

4. Найдём, когда Z₂ < Z₁:

200 000 + 300x < 100 000 + 500x
100 000 < 200x
x > 500
Ответ: при производстве более 500 единиц
