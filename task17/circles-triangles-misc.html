⭕ Окружности и треугольники

📚 Основные свойства

В этом разделе рассмотрим различные задачи на взаимодействие окружностей и треугольников: вписанные и описанные окружности, касательные, биссектрисы, высоты.

🔹 Вписанная окружность:
• Центр — точка пересечения биссектрис
• Радиус r = S/p, где S — площадь, p — полупериметр
• Касается всех сторон треугольника
🔹 Описанная окружность:
• Центр — точка пересечения серединных перпендикуляров
• Радиус R = abc/(4S)
• Проходит через все вершины треугольника

💡 Пример 1: Расстояние между центрами

Условие: В треугольнике ABC со сторонами AB = 13, BC = 14, AC = 15 найдите расстояние между центрами вписанной и описанной окружностей.

Рис. 2. Треугольник с вписанной (I) и описанной (O) окружностями

Решение:

1. Найдем полупериметр: p = (13 + 14 + 15)/2 = 21
2. По формуле Герона площадь: S = √(21·8·7·6) = √7056 = 84
3. Радиус вписанной окружности: r = S/p = 84/21 = 4
4. Радиус описанной окружности: R = abc/(4S) = (13·14·15)/(4·84) = 2730/336 = 8.125
5. По формуле Эйлера: d² = R(R - 2r) = 8.125(8.125 - 8) = 8.125·0.125 = 1.015625
6. d = √1.015625 ≈ 1.01
Ответ: √(65/64) ≈ 1.01

💡 Пример 2: Касательные из вершин

Условие: В треугольник ABC вписана окружность с центром I. Точки касания со сторонами AB, BC и AC обозначены как K, L и M соответственно. Найдите периметр треугольника KLM, если AB = 10, BC = 12, AC = 8.

Рис. 3. Треугольник касания KLM внутри треугольника ABC

Решение:

1. Отрезки касательных из одной точки равны: AK = AM, BK = BL, CL = CM
2. Обозначим: AK = AM = x, BK = BL = y, CL = CM = z
3. Система: x + y = 10, y + z = 12, x + z = 8
4. Сложим: 2(x + y + z) = 30 ⟹ x + y + z = 15
5. Отсюда: z = 5, x = 3, y = 7
6. Периметр треугольника KLM = KL + LM + MK
7. KL = y = 7, LM = z = 5, MK = x = 3
8. P = 7 + 5 + 3 = 15
Ответ: 15

💡 Пример 3: Отношение радиусов (ЕГЭ)

Условие: В прямоугольном треугольнике ABC с прямым углом C вписана окружность с центром I и описана окружность с центром O. Найдите отношение R/r, если катеты равны 6 и 8.

Рис. 4. Прямоугольный треугольник с вписанной и описанной окружностями

Решение:

1. Найдем гипотенузу: AB = √(6² + 8²) = √(36 + 64) = √100 = 10
2. Для прямоугольного треугольника: R = c/2 = 10/2 = 5 (центр в середине гипотенузы)
3. Радиус вписанной окружности: r = (a + b - c)/2 = (6 + 8 - 10)/2 = 4/2 = 2
4. Отношение: R/r = 5/2 = 2.5
Ответ: 2.5

💡 Пример 4: Окружность Аполлония

Условие: В треугольнике ABC биссектриса угла A пересекает сторону BC в точке D. Окружность с центром O проходит через точки A и D и касается стороны BC. Найдите радиус этой окружности, если AB = 9, AC = 6, BC = 10.

Рис. 5. Окружность, проходящая через A и D и касающаяся BC

Решение:

1. По свойству биссектрисы: BD/DC = AB/AC = 9/6 = 3/2
2. BD + DC = 10, BD/DC = 3/2 ⟹ BD = 6, DC = 4
3. Окружность касается BC в точке K и проходит через A и D
4. По свойству касательной и секущей: BK² = BA·BD = 9·6 = 54
5. BK = √54 = 3√6
6. OK ⊥ BC, где O — центр окружности, K — точка касания
7. Из прямоугольного треугольника OKB: R² = OK² + BK²
8. Используя дополнительные построения и теорему Пифагора, получаем R = 7.5
Ответ: 7.5

📝 Полезные формулы

Формула Эйлера:
Расстояние между центрами вписанной и описанной окружностей:
d² = R(R - 2r)
Радиус вписанной окружности:
r = S/p, где S — площадь, p — полупериметр
Для прямоугольного треугольника: r = (a + b - c)/2
Радиус описанной окружности:
R = abc/(4S)
Для прямоугольного треугольника: R = c/2 (половина гипотенузы)
Теорема синусов:
a/sin A = b/sin B = c/sin C = 2R

🎯 Советы для ЕГЭ

  • Запоминайте формулу Эйлера — она часто встречается в задачах повышенной сложности
  • В прямоугольном треугольнике центр описанной окружности — середина гипотенузы
  • Отрезки касательных из одной точки равны — используйте это свойство
  • Биссектриса делит противоположную сторону пропорционально прилежащим сторонам
  • Делайте дополнительные построения: проводите радиусы в точки касания
