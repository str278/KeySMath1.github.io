⭕ Вписанные окружности и треугольники

📚 Основные свойства

В этом разделе разбираем задачи, где окружность вписана в треугольник (касается всех трёх сторон).

🔹 Центр вписанной окружности:
• Точка пересечения биссектрис углов треугольника.
• Равноудалён от всех сторон треугольника (расстояние = радиусу r).
🔹 Отрезки касательных:
Отрезки, проведённые из одной вершины до точек касания, равны.
Если треугольник ABC касается окружности в точках K (на AB), L (на BC), M (на AC), то:
AK = AM, BK = BL, CL = CM.

💡 Пример 1: Прямоугольный треугольник

Условие: В прямоугольный треугольник с катетами 6 и 8 вписана окружность. Найдите её радиус.

Рис. 2. Вписанная окружность в прямоугольный треугольник

Решение:

1. Найдём гипотенузу по теореме Пифагора: c = √(6² + 8²) = √(36 + 64) = 10.
2. Для прямоугольного треугольника есть специальная формула радиуса: r = (a + b - c) / 2.
3. Подставляем: r = (6 + 8 - 10) / 2 = 4 / 2 = 2.
4. Проверка через площадь: S = (6×8)/2 = 24. Полупериметр p = (6+8+10)/2 = 12. r = S/p = 24/12 = 2.
Ответ: 2

💡 Пример 2: Равнобедренный треугольник

Условие: В равнобедренный треугольник с основанием 12 и боковой стороной 10 вписана окружность. Найдите её радиус.

Рис. 3. Вписанная окружность в равнобедренный треугольник

Решение:

1. Проведём высоту к основанию. Она делит основание пополам: 12 / 2 = 6.
2. По теореме Пифагора находим высоту: h = √(10² - 6²) = √(100 - 36) = √64 = 8.
3. Площадь треугольника: S = (основание × высота) / 2 = (12 × 8) / 2 = 48.
4. Полупериметр: p = (10 + 10 + 12) / 2 = 16.
5. Радиус вписанной окружности: r = S / p = 48 / 16 = 3.
Ответ: 3

💡 Пример 3: Задача с отрезками касательных (ЕГЭ)

Условие: В треугольник ABC вписана окружность с центром O. Точки касания делят стороны на отрезки: AK = 4, BK = 6, CL = 5. Найдите периметр треугольника и радиус вписанной окружности.

Рис. 4. Отрезки касательных из вершин треугольника

Решение:

1. Вспомним свойство: отрезки касательных из одной вершины равны. Значит, AM = AK = 4, BL = BK = 6, CM = CL = 5.
2. Находим стороны треугольника: AB = 4 + 6 = 10, BC = 6 + 5 = 11, AC = 4 + 5 = 9.
3. Периметр: P = 10 + 11 + 9 = 30. Полупериметр p = 15.
4. Площадь по формуле Герона: S = √(15 × 5 × 4 × 6) = √1800 = 30√2.
5. Радиус: r = S / p = 30√2 / 15 = 2√2.
Ответ: 30; 2√2

📝 Полезные формулы

Универсальная формула радиуса:
r = S / p
где S — площадь треугольника, p — полупериметр.
Для прямоугольного треугольника:
r = (a + b - c) / 2
где a, b — катеты, c — гипотенуза.
Отрезки от вершин до точек касания:
AK = AM = p - a
BK = BL = p - b
CL = CM = p - c
где a, b, c — стороны против вершин A, B, C.

🎯 Советы для ЕГЭ

  • Если в задаче даны отрезки касательных — сразу записывайте равенства отрезков из вершин.
  • В прямоугольном треугольнике используйте формулу r = (a+b-c)/2 — это быстрее, чем считать площадь.
  • Помните, что центр вписанной окружности лежит на пересечении биссектрис. Это помогает строить дополнительные углы.
  • Формула r = S/p работает для любого треугольника. Выучите её наизусть.
  • Не путайте вписанную окружность (касается сторон) и описанную (проходит через вершины).
