📐 Буквенные тригонометрические выражения

📚 Теория

Буквенные тригонометрические выражения — выражения, содержащие тригонометрические функции от буквенных аргументов.

🔹 Основные функции:
sin x, cos x
tan x, cot x
Тождественные преобразования
🔹 Методы преобразования:
  • Применение основных тригонометрических тождеств
  • Формулы приведения
  • Формулы суммы и разности
  • Формулы двойного угла

📐 Основные формулы

1. Основное тригонометрическое тождество:
$$ \sin^2 x + \cos^2 x = 1 $$
2. Формулы двойного угла:
$$ \sin 2x = 2 \sin x \cos x $$ $$ \cos 2x = \cos^2 x - \sin^2 x $$ $$ \tan 2x = \frac{2 \tan x}{1 - \tan^2 x} $$
3. Формулы приведения:
$$ \sin(\pi - x) = \sin x $$ $$ \cos(\pi - x) = -\cos x $$ $$ \sin\left(\frac{\pi}{2} - x\right) = \cos x $$

💡 Пример решения (ЕГЭ)

Условие: Упростите выражение: (sin x + cos x)² + (sin x − cos x)²

Решение:

1. Раскроем скобки:

(sin x + cos x)² = sin²x + 2sin x cos x + cos²x
(sin x − cos x)² = sin²x − 2sin x cos x + cos²x

2. Сложим:

(sin²x + 2sin x cos x + cos²x) + (sin²x − 2sin x cos x + cos²x)
= 2sin²x + 2cos²x = 2(sin²x + cos²x)

3. Применим основное тождество:

2 · 1 = 2
Ответ: 2
