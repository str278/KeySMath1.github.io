📐 Физический смысл производной

📚 Теория

Физический смысл производной — производная показывает скорость изменения функции.

🔹 Физические приложения:
v(t) = x'(t) — скорость (производная пути по времени)
a(t) = v'(t) — ускорение (производная скорости)
I(t) = q'(t) — сила тока (производная заряда)
🔹 Основные применения:
  • Механическое движение: v = dx/dt
  • Электрический ток: I = dq/dt
  • Теплоёмкость: C = dQ/dT
  • Мощность: P = dA/dt

Производная как скорость изменения

v(t₀) = x'(t₀)
Скорость равна производной пути по времени

📐 Основные формулы

1. Скорость движения:
$$ v(t) = \frac{dx}{dt} = x'(t) $$
2. Ускорение:
$$ a(t) = \frac{dv}{dt} = v'(t) = x''(t) $$
3. Сила тока:
$$ I(t) = \frac{dq}{dt} = q'(t) $$
4. Мощность:
$$ P(t) = \frac{dA}{dt} = A'(t) $$

💡 Пример решения (ЕГЭ)

Условие: Точка движется по закону x(t) = 2t² + 3t + 1. Найдите скорость точки в момент времени t = 2.

Решение:

1. Найдём производную (скорость):

v(t) = x'(t) = (2t² + 3t + 1)'
v(t) = 4t + 3

2. Найдём скорость в момент t = 2:

v(2) = 4 · 2 + 3 = 8 + 3 = 11
Ответ: 11
