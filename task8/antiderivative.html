📐 Первообразная

📚 Теория

Первообразная — функция F(x), производная которой равна данной функции f(x).

🔹 Обозначения:
F(x) — первообразная функции f(x)
F'(x) = f(x)
∫f(x)dx — неопределённый интеграл
🔹 Основные свойства:
  • Если F(x) — первообразная f(x), то F(x) + C — тоже первообразная
  • Любые две первообразные отличаются на постоянную
  • ∫f(x)dx = F(x) + C

📐 Основные формулы

1. Определение первообразной:
$$ F'(x) = f(x) \quad \Rightarrow \quad F(x) \text{ — первообразная } f(x) $$
2. Таблица первообразных:
$$ \int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1) $$ $$ \int \frac{1}{x} dx = \ln|x| + C $$ $$ \int e^x dx = e^x + C $$ $$ \int \sin x dx = -\cos x + C $$ $$ \int \cos x dx = \sin x + C $$
3. Правила интегрирования:
$$ \int (f(x) \pm g(x)) dx = \int f(x)dx \pm \int g(x)dx $$ $$ \int c \cdot f(x) dx = c \cdot \int f(x)dx $$

💡 Пример решения (ЕГЭ)

Условие: Найдите первообразную функции f(x) = 3x² − 2x + 1

Решение:

Проинтегрируем почленно:

F(x) = ∫(3x² − 2x + 1)dx
F(x) = 3∫x²dx − 2∫xdx + ∫1dx
F(x) = 3 · x³/3 − 2 · x²/2 + x + C
F(x) = x³ − x² + x + C
Ответ: F(x) = x³ − x² + x + C
