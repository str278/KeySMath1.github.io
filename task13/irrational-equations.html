🔍 Иррациональные уравнения

📚 Теория

Иррациональное уравнение — уравнение, содержащее переменную под знаком корня.

⚠️ Важно! При возведении в чётную степень могут появиться посторонние корни. Всегда делайте проверку!
🔹 Основные методы решения:
  • Возведение обеих частей в степень
  • Замена переменной
  • Проверка ОДЗ (область допустимых значений)
  • Проверка найденных корней

📐 Основные формулы

1. Уравнение вида √f(x) = a:

$$ \sqrt{f(x)} = a \quad (a \geq 0) $$ $$ f(x) = a^2 $$

ОДЗ: f(x) ≥ 0

2. Уравнение вида √f(x) = √g(x):

$$ \sqrt{f(x)} = \sqrt{g(x)} $$ $$ f(x) = g(x) $$

ОДЗ: f(x) ≥ 0, g(x) ≥ 0

3. Уравнение вида √f(x) = g(x):

$$ \sqrt{f(x)} = g(x) $$ $$ \begin{cases} f(x) = g^2(x) \\ g(x) \geq 0 \end{cases} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: √(x+3) = 4

Решение:

1. Найдём ОДЗ:

x + 3 ≥ 0 ⇒ x ≥ −3

2. Возведём обе части в квадрат:

(√(x+3))² = 4²
x + 3 = 16
x = 13

3. Проверка: 13 ≥ −3 ✓

Ответ: 13

Пример 2: Решите уравнение: √(x+3) + √(x-1) = 4

Решение:

1. Найдём ОДЗ:

x + 3 ≥ 0 ⇒ x ≥ −3
x − 1 ≥ 0 ⇒ x ≥ 1
Общее: x ≥ 1

2. Перенесём один корень:

√(x+3) = 4 − √(x-1)

3. Возведём в квадрат:

x + 3 = 16 − 8√(x-1) + (x-1)
x + 3 = 15 + x − 8√(x-1)
8√(x-1) = 12
√(x-1) = 1.5

4. Ещё раз возведём в квадрат:

x − 1 = 2.25
x = 3.25

5. Проверка: 3.25 ≥ 1 ✓

Ответ: 3.25

Пример 3: Решите уравнение: √(2x+5) = x+1

Решение:

1. Найдём ОДЗ:

2x + 5 ≥ 0 ⇒ x ≥ −2.5
x + 1 ≥ 0 ⇒ x ≥ −1
Общее: x ≥ −1

2. Возведём в квадрат:

2x + 5 = (x+1)²
2x + 5 = x² + 2x + 1
x² = 4
x = ±2

3. Проверка по ОДЗ (x ≥ −1):

x = 2 подходит ✓
x = −2 не подходит ✗
Ответ: 2
