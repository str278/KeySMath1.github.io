📐 Тригонометрические уравнения, сводимые к квадратным

📚 Теория

Тригонометрические уравнения, сводимые к квадратным — уравнения вида a·sin²x + b·sin x + c = 0 или аналогичные с cos x, tg x.

🔹 Алгоритм решения:
  1. Замена переменной: t = sin x (или cos x, tg x)
  2. Решение квадратного уравнения at² + bt + c = 0
  3. Возврат к переменной x
  4. Отбор корней (если требуется)

📐 Основные формулы

1. Основное тригонометрическое тождество:

$$ \sin^2 x + \cos^2 x = 1 $$
2. Формулы перехода:

$$ \sin^2 x = 1 - \cos^2 x $$ $$ \cos^2 x = 1 - \sin^2 x $$
3. Простейшие тригонометрические уравнения:

$$ \sin x = a \quad (|a| \leq 1) $$ $$ x = (-1)^n \arcsin a + \pi n, \quad n \in \mathbb{Z} $$ $$ \cos x = a \quad (|a| \leq 1) $$ $$ x = \pm \arccos a + 2\pi n, \quad n \in \mathbb{Z} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: 2sin²x − 3sin x + 1 = 0

Решение:

1. Сделаем замену t = sin x:

2t² − 3t + 1 = 0

2. Решим квадратное уравнение:

D = 9 − 8 = 1
t₁ = 1, t₂ = 0.5

3. Вернёмся к переменной x:

sin x = 1 ⇒ x = π/2 + 2πn
sin x = 0.5 ⇒ x = (−1)ⁿ·π/6 + πn
Ответ: π/2 + 2πn; (−1)ⁿ·π/6 + πn, n ∈ Z

Пример 2: Решите уравнение: cos²x + 3cos x − 4 = 0

Решение:

1. Сделаем замену t = cos x:

t² + 3t − 4 = 0

2. Решим квадратное уравнение:

D = 9 + 16 = 25
t₁ = 1, t₂ = −4

3. Вернёмся к переменной x:

cos x = 1 ⇒ x = 2πn
cos x = −4 — нет решений (|cos x| ≤ 1)
Ответ: 2πn, n ∈ Z
