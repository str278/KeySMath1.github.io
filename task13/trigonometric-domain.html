🔍 Тригонометрические уравнения, исследование ОДЗ

📚 Теория

Исследование ОДЗ (области допустимых значений) — важнейший этап решения тригонометрических уравнений, особенно когда присутствуют дроби, корни или логарифмы.

⚠️ Важно! Всегда проверяйте:
  • Знаменатель ≠ 0
  • Выражение под корнем ≥ 0
  • Выражение под логарифмом > 0
  • tg x и ctg x определены
🔹 Ограничения тригонометрических функций:
  • tg x определён при x ≠ π/2 + πn
  • ctg x определён при x ≠ πn
  • arcsin x определён при x ∈ [−1; 1]
  • arccos x определён при x ∈ [−1; 1]

📐 Основные ограничения

1. Тангенс и котангенс:

$$ \tan x \text{ определён при } x \neq \frac{\pi}{2} + \pi n, \quad n \in \mathbb{Z} $$ $$ \cot x \text{ определён при } x \neq \pi n, \quad n \in \mathbb{Z} $$
2. Обратные тригонометрические функции:

$$ \arcsin x, \arccos x \text{ определены при } x \in [-1; 1] $$
3. Дроби:

$$ \frac{f(x)}{g(x)} \text{ определено при } g(x) \neq 0 $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: tg x = 1

Решение:

1. Найдём ОДЗ:

x ≠ π/2 + πn, n ∈ Z

2. Решим уравнение:

x = arctg(1) + πn
x = π/4 + πn, n ∈ Z

3. Проверка по ОДЗ: π/4 + πn ≠ π/2 + πk ✓

Ответ: π/4 + πn, n ∈ Z

Пример 2: Решите уравнение: (sin x − 0.5)/cos x = 0

Решение:

1. Найдём ОДЗ:

cos x ≠ 0
x ≠ π/2 + πn

2. Дробь равна 0, когда числитель = 0:

sin x − 0.5 = 0
sin x = 0.5
x = (−1)ⁿ·π/6 + πn

3. Проверка по ОДЗ: cos((−1)ⁿ·π/6 + πn) ≠ 0 ✓

Ответ: (−1)ⁿ·π/6 + πn, n ∈ Z
