📐 Тригонометрические уравнения, сводимые к однородным

📚 Теория

Однородное тригонометрическое уравнение — уравнение вида a·sin x + b·cos x = 0 или a·sin²x + b·sin x·cos x + c·cos²x = 0.

🔹 Однородные уравнения 1-й степени:

Уравнение вида: a·sin x + b·cos x = 0

Решение: делим на cos x (при cos x ≠ 0) и получаем: a·tg x + b = 0

🔹 Однородные уравнения 2-й степени:

Уравнение вида: a·sin²x + b·sin x·cos x + c·cos²x = 0

Решение: делим на cos²x (при cos x ≠ 0) и получаем квадратное уравнение относительно tg x

📐 Основные формулы

1. Однородное уравнение 1-й степени:

$$ a\sin x + b\cos x = 0 \quad (a \neq 0, b \neq 0) $$ $$ \text{Делим на } \cos x: \quad a\tan x + b = 0 $$ $$ \tan x = -\frac{b}{a} $$ $$ x = \arctan\left(-\frac{b}{a}\right) + \pi n, \quad n \in \mathbb{Z} $$
2. Однородное уравнение 2-й степени:

$$ a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0 $$ $$ \text{Делим на } \cos^2 x: \quad a\tan^2 x + b\tan x + c = 0 $$
3. Случай cos x = 0:

$$ \cos x = 0 \Rightarrow x = \frac{\pi}{2} + \pi n, \quad n \in \mathbb{Z} $$

Нужно проверить, является ли это решение исходного уравнения

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: 2sin x − 3cos x = 0

Решение:

1. Разделим обе части на cos x (cos x ≠ 0):

2tg x − 3 = 0

2. Найдём tg x:

2tg x = 3
tg x = 1.5

3. Общее решение:

x = arctg(1.5) + πn, n ∈ Z
Ответ: arctg(1.5) + πn, n ∈ Z

Пример 2: Решите уравнение: sin²x + 2sin x·cos x − 3cos²x = 0

Решение:

1. Разделим на cos²x (cos x ≠ 0):

tg²x + 2tg x − 3 = 0

2. Замена t = tg x:

t² + 2t − 3 = 0

3. Решим квадратное уравнение:

D = 4 + 12 = 16
t₁ = 1, t₂ = −3

4. Возврат к x:

tg x = 1 ⇒ x = π/4 + πn
tg x = −3 ⇒ x = arctg(−3) + πn
Ответ: π/4 + πn; arctg(−3) + πn, n ∈ Z
