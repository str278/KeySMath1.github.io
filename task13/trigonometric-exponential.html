📈 Тригонометрия и показательные выражения

📚 Теория

Уравнения, содержащие тригонометрические и показательные функции — уравнения, в которых переменная содержится и в показателе степени, и в тригонометрической функции.

🔹 Основные методы:
  • Оценка области значений
  • Использование ограниченности тригонометрических функций
  • Логарифмирование
  • Замена переменной

📐 Основные формулы

1. Ограниченность тригонометрических функций:

$$ -1 \leq \sin x \leq 1, \quad -1 \leq \cos x \leq 1 $$
2. Свойства показательной функции:

$$ a^x > 0 \text{ для всех } x \in \mathbb{R}, a > 0 $$ $$ a^x \text{ возрастает при } a > 1 $$ $$ a^x \text{ убывает при } 0 < a < 1 $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: 2sin x = 1

Решение:

1. Представим 1 как степень двойки:

2sin x = 2⁰

2. Приравняем показатели:

sin x = 0

3. Решим уравнение:

x = πn, n ∈ Z
Ответ: πn, n ∈ Z

Пример 2: Решите уравнение: 3cos x = √3

Решение:

1. Представим √3 как степень тройки:

3cos x = 31/2

2. Приравняем показатели:

cos x = 1/2

3. Решим уравнение:

x = ±π/3 + 2πn, n ∈ Z
Ответ: ±π/3 + 2πn, n ∈ Z
