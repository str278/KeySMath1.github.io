√ Тригонометрия и иррациональности

📚 Теория

Тригонометрические уравнения с иррациональностями — уравнения, содержащие тригонометрические функции под знаком корня или корни из тригонометрических функций.

⚠️ Важно! При решении таких уравнений необходимо:
  • Учитывать ОДЗ: выражение под корнем ≥ 0
  • Помнить, что |sin x| ≤ 1, |cos x| ≤ 1
  • Проверять найденные корни подстановкой
🔹 Основные методы:
  • Возведение в квадрат с последующей проверкой
  • Замена переменной
  • Использование основного тригонометрического тождества
  • Оценка области значений

📐 Основные формулы

1. Уравнение вида √f(x) = g(x):

$$ \sqrt{f(x)} = g(x) $$ $$ \begin{cases} f(x) = g^2(x) \\ g(x) \geq 0 \\ f(x) \geq 0 \end{cases} $$
2. Уравнение вида √(sin x) = a:

$$ \sqrt{\sin x} = a \quad (a \geq 0) $$ $$ \begin{cases} \sin x = a^2 \\ 0 \leq a^2 \leq 1 \end{cases} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: √(1 − cos x) = sin x

Решение:

1. Найдём ОДЗ:

1 − cos x ≥ 0 (всегда верно, т.к. cos x ≤ 1)
sin x ≥ 0

2. Возведём в квадрат:

1 − cos x = sin²x
1 − cos x = 1 − cos²x
cos²x − cos x = 0
cos x(cos x − 1) = 0

3. Решаем:

cos x = 0 ⇒ x = π/2 + πn
cos x = 1 ⇒ x = 2πn

4. Проверка по ОДЗ (sin x ≥ 0):

x = π/2 + 2πn: sin(π/2) = 1 ≥ 0 ✓
x = 2πn: sin(0) = 0 ≥ 0 ✓
Ответ: π/2 + 2πn; 2πn, n ∈ Z
