📊 Тригонометрия и логарифмы

📚 Теория

Уравнения, содержащие тригонометрические и логарифмические функции — сложные уравнения, требующие одновременного применения свойств обеих функций.

⚠️ Важно! Необходимо учитывать ограничения обеих функций:
  • ОДЗ для логарифма: выражение > 0
  • Основание логарифма > 0 и ≠ 1
  • Ограничения тригонометрических функций
🔹 Основные методы:
  • Замена переменной
  • Логарифмирование обеих частей
  • Использование свойств логарифмов
  • Тщательная проверка ОДЗ

📐 Основные формулы

1. Уравнение вида loga(f(x)) = g(x):

$$ \log_a(f(x)) = g(x) $$ $$ f(x) = a^{g(x)} $$

ОДЗ: f(x) > 0, a > 0, a ≠ 1

2. Уравнение вида loga(sin x) = b:

$$ \log_a(\sin x) = b $$ $$ \sin x = a^b $$

ОДЗ: 0 < sin x ≤ 1, a > 0, a ≠ 1

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: log₂(sin x) = −1

Решение:

1. Найдём ОДЗ:

sin x > 0
x ∈ (2πn; π + 2πn)

2. Потенцируем:

sin x = 2⁻¹
sin x = 0.5

3. Решаем:

x = (−1)ⁿ·π/6 + πn

4. Отбор по ОДЗ (sin x > 0):

x = π/6 + 2πn
x = 5π/6 + 2πn
Ответ: π/6 + 2πn; 5π/6 + 2πn, n ∈ Z
