📊 Логарифмические уравнения

📚 Теория

Логарифмическое уравнение — уравнение, в котором переменная содержится под знаком логарифма.

⚠️ Важно! Всегда проверяйте ОДЗ: выражение под логарифмом должно быть > 0, основание логарифма > 0 и ≠ 1.
🔹 Основные методы решения:
  • Приведение к одному основанию
  • Потенцирование (переход от логарифмов к показателям)
  • Замена переменной
  • Использование свойств логарифмов

📐 Основные формулы

1. Определение логарифма:

$$ \log_a b = c \Leftrightarrow a^c = b $$

ОДЗ: a > 0, a ≠ 1, b > 0

2. Основное логарифмическое тождество:

$$ a^{\log_a b} = b $$
3. Свойства логарифмов:

$$ \log_a (xy) = \log_a x + \log_a y $$ $$ \log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y $$ $$ \log_a (x^p) = p \log_a x $$ $$ \log_a a = 1, \quad \log_a 1 = 0 $$
4. Формула перехода к новому основанию:

$$ \log_a b = \frac{\log_c b}{\log_c a} $$
5. Уравнение вида loga f(x) = b:

$$ \log_a f(x) = b $$ $$ f(x) = a^b $$
6. Уравнение вида loga f(x) = loga g(x):

$$ \log_a f(x) = \log_a g(x) $$ $$ \begin{cases} f(x) = g(x) \\ f(x) > 0 \\ g(x) > 0 \end{cases} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: log₂(x + 3) = 3

Решение:

1. Найдём ОДЗ:

x + 3 > 0 ⇒ x > −3

2. Потенцируем (перейдём от логарифма):

x + 3 = 2³
x + 3 = 8
x = 5

3. Проверка: 5 > −3 ✓

Ответ: 5

Пример 2: Решите уравнение: log₃(27) + log₅(125)

Решение:

1. Найдём каждое слагаемое:

log₃(27) = log₃(3³) = 3
log₅(125) = log₅(5³) = 3

2. Сложим:

3 + 3 = 6
Ответ: 6

Пример 3: Решите уравнение: log₂(x² − 3x + 2) = 1

Решение:

1. Найдём ОДЗ:

x² − 3x + 2 > 0
(x−1)(x−2) > 0
x ∈ (−∞; 1) ∪ (2; +∞)

2. Потенцируем:

x² − 3x + 2 = 2¹
x² − 3x + 2 = 2
x² − 3x = 0
x(x − 3) = 0
x = 0 или x = 3

3. Проверка по ОДЗ:

x = 0 ∈ (−∞; 1) ✓
x = 3 ∈ (2; +∞) ✓
Ответ: 0; 3
