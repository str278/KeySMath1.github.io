📊 Рациональные уравнения

📚 Теория

Рациональное уравнение — уравнение вида P(x)/Q(x) = 0, где P(x) и Q(x) — многочлены.

⚠️ Важно! Знаменатель не должен быть равен нулю. Всегда проверяйте ОДЗ: Q(x) ≠ 0
🔹 Алгоритм решения:
  1. Найти ОДЗ: Q(x) ≠ 0
  2. Приравнять числитель к нулю: P(x) = 0
  3. Решить уравнение P(x) = 0
  4. Исключить корни, обращающие знаменатель в ноль

📐 Основные формулы

1. Уравнение вида P(x)/Q(x) = 0:

$$ \frac{P(x)}{Q(x)} = 0 $$ $$ \begin{cases} P(x) = 0 \\ Q(x) \neq 0 \end{cases} $$
2. Уравнение вида P(x)/Q(x) = R(x)/S(x):

$$ \frac{P(x)}{Q(x)} = \frac{R(x)}{S(x)} $$ $$ P(x) \cdot S(x) = Q(x) \cdot R(x) $$

ОДЗ: Q(x) ≠ 0, S(x) ≠ 0

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: (x² − 4)/(x − 2) = 0

Решение:

1. Найдём ОДЗ:

x − 2 ≠ 0 ⇒ x ≠ 2

2. Приравняем числитель к нулю:

x² − 4 = 0
(x−2)(x+2) = 0
x = 2 или x = −2

3. Проверка по ОДЗ:

x = 2 — не подходит (знаменатель = 0)
x = −2 — подходит ✓
Ответ: −2
