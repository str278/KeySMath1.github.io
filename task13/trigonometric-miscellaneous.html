🎯 Тригонометрические уравнения, разные задачи

📚 Теория

В этом разделе собраны различные типы тригонометрических уравнений, которые не вошли в предыдущие категории или требуют комбинированного подхода.

🔹 Основные типы задач:
  • Уравнения с несколькими тригонометрическими функциями
  • Уравнения, требующие применения нескольких формул
  • Уравнения с отбором корней на промежутке
  • Уравнения с параметром

📐 Полезные формулы

1. Формулы приведения:

$$ \sin(\pi - x) = \sin x, \quad \cos(\pi - x) = -\cos x $$ $$ \sin(\pi/2 - x) = \cos x, \quad \cos(\pi/2 - x) = \sin x $$
2. Формулы суммы и разности:

$$ \sin(x \pm y) = \sin x\cos y \pm \cos x\sin y $$ $$ \cos(x \pm y) = \cos x\cos y \mp \sin x\sin y $$
3. Формулы двойного угла:

$$ \sin 2x = 2\sin x\cos x $$ $$ \cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: sin x + cos x = 1

Решение:

1. Возведём обе части в квадрат:

(sin x + cos x)² = 1²
sin²x + 2sin x·cos x + cos²x = 1
1 + sin 2x = 1
sin 2x = 0

2. Решим уравнение:

2x = πn
x = πn/2

3. Проверка подстановкой в исходное уравнение:

x = 0: sin 0 + cos 0 = 0 + 1 = 1 ✓
x = π/2: sin(π/2) + cos(π/2) = 1 + 0 = 1 ✓
x = π: sin π + cos π = 0 + (−1) = −1 ✗
Ответ: 2πn; π/2 + 2πn, n ∈ Z
