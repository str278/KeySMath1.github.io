✖️ Тригонометрические уравнения, разложение на множители

📚 Теория

Метод разложения на множители — один из основных методов решения тригонометрических уравнений. Уравнение приводится к виду f(x)·g(x) = 0.

🔹 Алгоритм решения:
  1. Преобразовать уравнение к виду f(x)·g(x) = 0
  2. Решить уравнения f(x) = 0 и g(x) = 0 отдельно
  3. Объединить все найденные решения
🔹 Основные приёмы разложения:
  • Вынесение общего множителя за скобки
  • Группировка слагаемых
  • Применение формул сокращённого умножения
  • Использование тригонометрических формул

📐 Основные формулы

1. Уравнение вида f(x)·g(x) = 0:

$$ f(x) \cdot g(x) = 0 $$ $$ \Leftrightarrow \begin{cases} f(x) = 0 \\ \text{или} \\ g(x) = 0 \end{cases} $$
2. Формулы для разложения:

$$ \sin 2x = 2\sin x\cos x $$ $$ \cos 2x = \cos^2 x - \sin^2 x $$ $$ \sin x - \sin y = 2\sin\frac{x-y}{2}\cos\frac{x+y}{2} $$ $$ \cos x - \cos y = -2\sin\frac{x-y}{2}\sin\frac{x+y}{2} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: sin x · (2cos x − 1) = 0

Решение:

1. Уравнение уже разложено на множители. Решаем каждое:

2. Первый множитель:

sin x = 0
x = πn, n ∈ Z

3. Второй множитель:

2cos x − 1 = 0
cos x = 0.5
x = ±π/3 + 2πn, n ∈ Z
Ответ: πn; ±π/3 + 2πn, n ∈ Z

Пример 2: Решите уравнение: sin 2x − sin x = 0

Решение:

1. Применим формулу sin 2x = 2sin x·cos x:

2sin x·cos x − sin x = 0

2. Вынесем sin x за скобки:

sin x(2cos x − 1) = 0

3. Решаем каждое уравнение:

sin x = 0 ⇒ x = πn
2cos x − 1 = 0 ⇒ cos x = 0.5 ⇒ x = ±π/3 + 2πn
Ответ: πn; ±π/3 + 2πn, n ∈ Z

Пример 3: Решите уравнение: cos 2x − cos x = 0

Решение:

1. Применим формулу разности косинусов:

cos 2x − cos x = −2sin((2x+x)/2)·sin((2x−x)/2)
= −2sin(3x/2)·sin(x/2) = 0

2. Решаем каждое уравнение:

sin(3x/2) = 0 ⇒ 3x/2 = πn ⇒ x = 2πn/3
sin(x/2) = 0 ⇒ x/2 = πn ⇒ x = 2πn
Ответ: 2πn/3; 2πn, n ∈ Z
