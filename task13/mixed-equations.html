🔀 Смешанные уравнения

📚 Теория

Смешанные уравнения — уравнения, содержащие комбинацию различных типов функций: показательных, логарифмических, тригонометрических, иррациональных и рациональных.

⚠️ Важно! При решении смешанных уравнений:
  • Тщательно находите ОДЗ для всех функций
  • Используйте свойства каждой функции
  • Проверяйте найденные корни подстановкой
  • Применяйте метод оценок
🔹 Стратегия решения:
  1. Найти ОДЗ для всех функций в уравнении
  2. Проанализировать структуру уравнения
  3. Выбрать подходящий метод (замена, оценка, логарифмирование)
  4. Решить полученное уравнение
  5. Проверить корни на соответствие ОДЗ

📐 Основные методы

1. Метод оценки:

Если уравнение имеет вид f(x) = g(x), где:

  • f(x) ≥ a для всех x из ОДЗ
  • g(x) ≤ a для всех x из ОДЗ

то уравнение равносильно системе:

$$ \begin{cases} f(x) = a \\ g(x) = a \end{cases} $$
2. Метод замены переменной:

Если уравнение содержит повторяющиеся выражения, сделать замену:

$$ t = \text{повторяющееся выражение} $$

Решить уравнение относительно t, затем вернуться к x

💡 Примеры решения (ЕГЭ)

Пример 1: Решите уравнение: 2x + log₂x = 1

Решение:

1. Найдём ОДЗ:

x > 0

2. Оценим функции:

2x > 0 при всех x
log₂x может быть любым

3. Подбором находим решение:

При x = 0.5:
20.5 + log₂(0.5) = √2 + (−1) ≈ 1.41 − 1 ≈ 0.41 ≠ 1
При x = 1:
2¹ + log₂1 = 2 + 0 = 2 ≠ 1

4. Графический или численный метод:

Уравнение имеет единственное решение x ≈ 0.64
Ответ: x ≈ 0.64
