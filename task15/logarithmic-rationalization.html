🔄 Неравенства с логарифмами и рационализацией

📚 Теория

Метод рационализации — метод решения логарифмических неравенств с переменным основанием, основанный на замене логарифма рациональным выражением.

🔹 Основная формула рационализации:

Для неравенства вида logh(x)f(x) ⋈ logh(x)g(x) используется замена:

📐 Основные формулы

1. Формула рационализации:

$$ \log_{h(x)} f(x) - \log_{h(x)} g(x) \bowtie 0 $$ $$ \Updownarrow $$ $$ (h(x) - 1)(f(x) - g(x)) \bowtie 0 $$

при условии f(x) > 0, g(x) > 0, h(x) > 0, h(x) ≠ 1

2. Частный случай:

$$ \log_{h(x)} f(x) \bowtie 0 $$ $$ \Updownarrow $$ $$ (h(x) - 1)(f(x) - 1) \bowtie 0 $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: logx+2(x² − 1) ≥ 0

Решение:

1. Найдём ОДЗ:

x² − 1 > 0 ⇒ x ∈ (−∞; −1) ∪ (1; +∞)
x + 2 > 0 ⇒ x > −2
x + 2 ≠ 1 ⇒ x ≠ −1
ОДЗ: x ∈ (−2; −1) ∪ (1; +∞)

2. Применим метод рационализации:

(x+2−1)(x²−1−1) ≥ 0
(x+1)(x²−2) ≥ 0

3. Решим неравенство методом интервалов:

x ∈ [−√2; −1] ∪ [√2; +∞)

4. Пересечём с ОДЗ:

x ∈ (−2; −1) ∪ [√2; +∞)
Ответ: (−2; −1) ∪ [√2; +∞)
