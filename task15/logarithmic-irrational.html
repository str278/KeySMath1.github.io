📊√ Логарифмы и иррациональности

📚 Теория

Неравенства, содержащие одновременно логарифмические и иррациональные выражения — требуют тщательного учёта ОДЗ и применения методов решения обоих типов неравенств.

⚠️ Важно! Необходимо учитывать:
  • ОДЗ для логарифма: выражение > 0
  • ОДЗ для корня: выражение ≥ 0
  • Основание логарифма > 0 и ≠ 1
🔹 Основные методы:
  • Поэтапное нахождение ОДЗ
  • Замена переменной
  • Возведение в степень с учётом ОДЗ
  • Метод интервалов

📐 Основные формулы

1. Общий вид:

$$ \log_a f(x) \bowtie \sqrt{g(x)} $$

ОДЗ: f(x) > 0, g(x) ≥ 0, a > 0, a ≠ 1

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: log₂x ≥ √x

Решение:

1. Найдём ОДЗ:

x > 0

2. Рассмотрим функцию f(x) = log₂x − √x

3. Проверим значения:

При x = 1: log₂1 = 0, √1 = 1 ⇒ 0 < 1 ✗
При x = 4: log₂4 = 2, √4 = 2 ⇒ 2 = 2 ✓
При x = 16: log₂16 = 4, √16 = 4 ⇒ 4 = 4 ✓

4. Графически или методом оценки находим:

x ∈ [4; 16]
Ответ: [4; 16]
