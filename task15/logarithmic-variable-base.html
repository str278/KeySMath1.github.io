🔀 Неравенства с логарифмами по переменному основанию

📚 Теория

Логарифмические неравенства с переменным основанием — неравенства, где основание логарифма содержит переменную.

⚠️ Важно! Необходимо рассматривать два случая:
  • Основание > 1
  • 0 < Основание < 1
🔹 Алгоритм решения:
  1. Найти ОДЗ для основания и подлогарифмического выражения
  2. Рассмотреть случай a(x) > 1
  3. Рассмотреть случай 0 < a(x) < 1
  4. Объединить решения

📐 Основные формулы

1. Неравенство вида loga(x)f(x) > loga(x)g(x):

$$ \log_{a(x)} f(x) > \log_{a(x)} g(x) $$ $$ \begin{cases} a(x) > 1: f(x) > g(x) > 0 \\ 0 < a(x) < 1: 0 < f(x) < g(x) \end{cases} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: logx4 > 2

Решение:

1. Найдём ОДЗ:

x > 0, x ≠ 1

2. Рассмотрим случаи:

Случай 1: x > 1

4 > x²
x² < 4
x ∈ (1; 2)

Случай 2: 0 < x < 1

4 < x²
x² > 4 — нет решений (x < 1)
Ответ: (1; 2)
