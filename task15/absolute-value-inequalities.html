📐 Неравенства с модулем

📚 Что такое модуль?

Модуль числа — это расстояние от этого числа до нуля на числовой прямой. Модуль всегда неотрицателен.

Рис. 1. Модуль — это расстояние до нуля (всегда положительно)
Определение:
|x| = x, если x ≥ 0
|x| = -x, если x < 0

🔧 Основные типы неравенств с модулем

Тип 1: |x| < a (меньше числа)

Рис. 2. Решение неравенства |x| < a
|x| < a ⟺ -a < x < a (при a > 0)

Тип 2: |x| > a (больше числа)

Рис. 3. Решение неравенства |x| > a
|x| > a ⟺ x < -a или x > a (при a > 0)

💡 Пример 1: Простое неравенство

Условие: Решите неравенство |2x - 3| < 5

Решение:

1. Применяем правило для |...| < a: -5 < 2x - 3 < 5
2. Прибавляем 3 ко всем частям: -5 + 3 < 2x < 5 + 3
3. Упрощаем: -2 < 2x < 8
4. Делим на 2: -1 < x < 4
Ответ: x ∈ (-1; 4)

💡 Пример 2: Неравенство с двумя модулями

Условие: Решите неравенство |x - 1| + |x - 3| < 4

Рис. 4. Разбиение числовой прямой на интервалы

Решение (метод интервалов):

Случай 1: x < 1

Оба выражения под модулем отрицательны: -(x-1) - (x-3) < 4
-x + 1 - x + 3 < 4 ⟺ -2x + 4 < 4 ⟺ -2x < 0 ⟺ x > 0
Пересекаем с условием x < 1: получаем x ∈ (0; 1)

Случай 2: 1 ≤ x < 3

Первое положительно, второе отрицательно: (x-1) - (x-3) < 4
x - 1 - x + 3 < 4 ⟺ 2 < 4 (всегда верно!)
Значит, весь интервал подходит: x ∈ [1; 3)

Случай 3: x ≥ 3

Оба положительны: (x-1) + (x-3) < 4
2x - 4 < 4 ⟺ 2x < 8 ⟺ x < 4
Пересекаем с x ≥ 3: получаем x ∈ [3; 4)
Объединяем все решения: (0; 1) ∪ [1; 3) ∪ [3; 4) = (0; 4)
Ответ: x ∈ (0; 4)

💡 Пример 3: Сложное неравенство (ЕГЭ)

Условие: Решите неравенство |x² - 4| ≤ x + 2

Решение:

Шаг 1. Находим точки, где выражение под модулем равно нулю

x² - 4 = 0 ⟺ x² = 4 ⟺ x = -2 или x = 2
Эти точки разбивают числовую прямую на три интервала

Шаг 2. Рассматриваем случай x < -2 или x > 2

Здесь x² - 4 > 0, значит |x² - 4| = x² - 4
Неравенство: x² - 4 ≤ x + 2 ⟺ x² - x - 6 ≤ 0
Корни: x = -2 и x = 3. Решение: x ∈ [-2; 3]
Пересекаем с условием (x < -2 или x > 2): получаем x ∈ (2; 3]

Шаг 3. Рассматриваем случай -2 ≤ x ≤ 2

Здесь x² - 4 ≤ 0, значит |x² - 4| = -(x² - 4) = 4 - x²
Неравенство: 4 - x² ≤ x + 2 ⟺ -x² - x + 2 ≤ 0 ⟺ x² + x - 2 ≥ 0
Корни: x = -2 и x = 1. Решение: x ∈ (-∞; -2] ∪ [1; +∞)
Пересекаем с условием -2 ≤ x ≤ 2: получаем x = -2 или x ∈ [1; 2]
Объединяем: {-2} ∪ [1; 2] ∪ (2; 3] = {-2} ∪ [1; 3]
Ответ: x ∈ {-2} ∪ [1; 3]

📝 Алгоритм решения неравенств с модулем

  1. Найдите критические точки — где выражения под модулем равны нулю
  2. Разбейте числовую прямую на интервалы этими точками
  3. На каждом интервале раскройте модули (учитывая знак)
  4. Решите неравенство на каждом интервале
  5. Пересеките решение с условием интервала
  6. Объедините все решения из всех интервалов
⚠️ Важные моменты:
  • Всегда проверяйте ОДЗ (область допустимых значений)
  • Не забывайте пересекать решение с условием интервала!
  • Если модуль больше отрицательного числа — неравенство верно всегда
  • Если модуль меньше отрицательного числа — решений нет

🎯 Советы для ЕГЭ

  • Метод интервалов — самый надёжный способ решения сложных неравенств с модулем
  • Всегда делайте проверку граничных точек
  • Если видите |f(x)| < g(x), сразу пишите двойное неравенство: -g(x) < f(x) < g(x)
  • Для |f(x)| > g(x) используйте совокупность: f(x) < -g(x) или f(x) > g(x)
  • В ответе записывайте в виде промежутков или объединения точек и промежутков
