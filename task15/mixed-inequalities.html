🔀 Смешанные неравенства

📚 Что такое смешанные неравенства?

Это неравенства, в которых комбинируются разные типы функций: показательные, логарифмические, тригонометрические, с модулем и т.д.

💡 Основная идея:
Разбить сложное неравенство на более простые системы или совокупности, используя свойства функций и метод интервалов.

Типичные комбинации:

  • Логарифм + модуль: log₂|x-1| > 2
  • Показательная + тригонометрия: 2^sin(x) ≤ 1
  • Корень + логарифм: √(x-2) < log₃(x)
  • Модуль + дробь: |x-1|/(x+2) ≥ 1

🔧 Общий алгоритм решения

Рис. 1. Алгоритм решения смешанных неравенств
  1. Найдите область допустимых значений (ОДЗ) — учтите ограничения всех функций
  2. Разбейте на случаи — по знакам выражений под модулем, по периодам тригонометрии и т.д.
  3. Решите каждое неравенство отдельно — используя соответствующие методы
  4. Объедините решения — с учетом ОДЗ

💡 Пример 1: Логарифм + Модуль

Условие: Решите неравенство log₂|x - 3| < 2

Решение:

Шаг 1. Находим ОДЗ

Под логарифмом должно быть положительно: |x - 3| > 0
Это значит: x - 3 ≠ 0 ⟺ x ≠ 3

Шаг 2. Раскрываем логарифм

log₂|x - 3| < 2 ⟺ |x - 3| < 2²
|x - 3| < 4

Шаг 3. Решаем неравенство с модулем

-4 < x - 3 < 4
Прибавляем 3: -1 < x < 7

Шаг 4. Учитываем ОДЗ

x ∈ (-1; 7), но x ≠ 3
Ответ: x ∈ (-1; 3) ∪ (3; 7)
Ответ: (-1; 3) ∪ (3; 7)

💡 Пример 2: Показательная + Тригонометрия

Условие: Решите неравенство 2^sin(x) ≤ 1 на промежутке [0; 2π]

Рис. 2. График sin(x) — решение там, где синус отрицателен

Решение:

Шаг 1. Анализируем показательную функцию

2^sin(x) ≤ 1
Так как 2 > 1, функция возрастает
Значит: sin(x) ≤ 0 (потому что 2⁰ = 1)

Шаг 2. Решаем тригонометрическое неравенство

sin(x) ≤ 0 на промежутке [0; 2π]
Синус отрицателен в 3-й и 4-й четвертях
x ∈ [π; 2π]
Ответ: [π; 2π]

💡 Пример 3: Корень + Логарифм (ЕГЭ)

Условие: Решите неравенство √(x - 1) < log₂(x)

Решение:

Шаг 1. Находим ОДЗ

Под корнем: x - 1 ≥ 0 ⟺ x ≥ 1
Под логарифмом: x > 0
Общее ОДЗ: x ≥ 1

Шаг 2. Анализируем поведение функций

При x = 1: √(1-1) = 0, log₂(1) = 0. Равенство!
При x = 2: √(2-1) = 1, log₂(2) = 1. Снова равенство!
При x = 4: √(4-1) = √3 ≈ 1.73, log₂(4) = 2

Шаг 3. Сравниваем скорости роста

На промежутке (1; 2): корень растет быстрее логарифма
На промежутке (2; +∞): логарифм догоняет корень
Проверяем x = 5: √4 = 2, log₂(5) ≈ 2.32 — логарифм больше!

Шаг 4. Делаем вывод

√(x - 1) < log₂(x) при x > 2
Проверяем: при x = 3: √2 ≈ 1.41, log₂(3) ≈ 1.58 ✓
Ответ: (2; +∞)

💡 Пример 4: Модуль + Дробь

Условие: Решите неравенство |x - 2|/(x + 1) ≥ 1

Решение:

Шаг 1. Находим ОДЗ

Знаменатель не равен нулю: x + 1 ≠ 0 ⟺ x ≠ -1

Шаг 2. Переносим всё в одну сторону

|x - 2|/(x + 1) - 1 ≥ 0
(|x - 2| - (x + 1))/(x + 1) ≥ 0

Шаг 3. Разбираем случаи для модуля

Случай 1: x ≥ 2

|x - 2| = x - 2
(x - 2 - x - 1)/(x + 1) ≥ 0
-3/(x + 1) ≥ 0
Дробь положительна, когда знаменатель отрицателен: x + 1 < 0
x < -1, но это противоречит условию x ≥ 2
Решений нет

Случай 2: x < 2

|x - 2| = -(x - 2) = 2 - x
(2 - x - x - 1)/(x + 1) ≥ 0
(1 - 2x)/(x + 1) ≥ 0
Метод интервалов: критические точки x = -1 и x = 0.5
Расставляем знаки: (+) на (-∞; -1), (-) на (-1; 0.5], (+) на [0.5; 2)
Нам нужно ≥ 0: x ∈ (-∞; -1) ∪ [0.5; 2)
Объединяем с ОДЗ: x ∈ (-∞; -1) ∪ [0.5; 2)
Ответ: (-∞; -1) ∪ [0.5; 2)
⚠️ Важные моменты:
  • Всегда начинайте с нахождения ОДЗ — это сэкономит время и избежит ошибок
  • Проверяйте граничные точки — они часто дают равенство
  • Если не получается аналитически — постройте график или проверьте несколько точек
  • Не забывайте про знак знаменателя при работе с дробями

🎯 Советы для ЕГЭ

  • Если видите сложное смешанное неравенство — не паникуйте, разбейте его на части
  • Часто достаточно проверить несколько характерных точек
  • Запоминайте стандартные значения: log₂(2) = 1, log₂(4) = 2, sin(π/6) = 0.5 и т.д.
  • Если в ответе получается «красивое» число — скорее всего, вы решили правильно
  • Всегда делайте проверку подстановкой хотя бы одной точки из ответа
