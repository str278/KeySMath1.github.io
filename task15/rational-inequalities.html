📊 Рациональные неравенства

📚 Теория

Рациональное неравенство — неравенство вида P(x)/Q(x) ⋛ 0, где P(x) и Q(x) — многочлены.

⚠️ Важно! Знаменатель не должен быть равен нулю. Метод интервалов — основной метод решения.
🔹 Алгоритм решения (метод интервалов):
  1. Привести к виду P(x)/Q(x) ⋛ 0
  2. Разложить числитель и знаменатель на множители
  3. Найти нули числителя и знаменателя
  4. Отметить точки на числовой прямой
  5. Определить знаки на интервалах
  6. Выбрать нужные интервалы

📐 Основные формулы

1. Неравенство вида P(x)/Q(x) > 0:

$$ \frac{P(x)}{Q(x)} > 0 $$ $$ \Leftrightarrow \begin{cases} P(x) > 0 \\ Q(x) > 0 \end{cases} \text{ или } \begin{cases} P(x) < 0 \\ Q(x) < 0 \end{cases} $$
2. Неравенство вида P(x)/Q(x) ≥ 0:

$$ \frac{P(x)}{Q(x)} \geq 0 $$ $$ \Leftrightarrow \begin{cases} P(x) \geq 0 \\ Q(x) > 0 \end{cases} \text{ или } \begin{cases} P(x) \leq 0 \\ Q(x) < 0 \end{cases} $$

Важно: Q(x) ≠ 0

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: (x − 2)/(x + 3) > 0

Решение:

1. Найдём нули числителя и знаменателя:

x − 2 = 0 ⇒ x = 2
x + 3 = 0 ⇒ x = −3

2. Отметим на числовой прямой:

−3 и 2 делят прямую на 3 интервала

3. Определим знаки:

(−∞; −3): (+)/(−) = −
(−3; 2): (−)/(+) = −
(2; +∞): (+)/(+) = +

4. Выбираем интервалы, где дробь положительна:

x ∈ (−∞; −3) ∪ (2; +∞)
Ответ: (−∞; −3) ∪ (2; +∞)

Пример 2: Решите неравенство: (x² − 4)/(x − 1) ≥ 0

Решение:

1. Разложим числитель:

x² − 4 = (x−2)(x+2)

2. Неравенство принимает вид:

(x−2)(x+2)/(x−1) ≥ 0

3. Найдём нули:

x = −2, x = 2 (числитель)
x = 1 (знаменатель)

4. Метод интервалов:

x ∈ [−2; 1) ∪ [2; +∞)
Ответ: [−2; 1) ∪ [2; +∞)
