📊 Неравенства рациональные относительно показательной функции

📚 Теория

Неравенства, рациональные относительно показательной функции — неравенства, которые можно привести к виду рационального неравенства заменой переменной t = ax.

🔹 Алгоритм решения:
  1. Сделать замену t = ax (t > 0)
  2. Решить рациональное неравенство относительно t
  3. Вернуться к переменной x
  4. Учесть условие t > 0

📐 Основные формулы

1. Общая форма:

$$ R(a^x) \bowtie 0 $$

где R — рациональная функция, ⋈ — один из знаков: >, <, ≥, ≤

2. Замена переменной:

$$ t = a^x, \quad t > 0 $$ $$ x = \log_a t $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: 4x − 5·2x + 4 > 0

Решение:

1. Заметим, что 4x = (2x)². Сделаем замену:

t = 2x, t > 0

2. Получим квадратное неравенство:

t² − 5t + 4 > 0

3. Решим квадратное неравенство:

(t−1)(t−4) > 0
t ∈ (0; 1) ∪ (4; +∞)

4. Вернёмся к x:

2x < 1 ⇒ x < 0
2x > 4 ⇒ x > 2
Ответ: (−∞; 0) ∪ (2; +∞)
