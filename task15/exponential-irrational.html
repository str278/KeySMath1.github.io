√📈 Показательные выражения и иррациональности

📚 Теория

Неравенства, содержащие одновременно показательные и иррациональные выражения — требуют комбинированного подхода к решению.

⚠️ Важно! Необходимо учитывать:
  • ОДЗ для иррациональных выражений
  • Свойства показательной функции
  • Методы решения обоих типов неравенств
🔹 Основные методы:
  • Замена переменной
  • Оценка обеих частей неравенства
  • Метод интервалов
  • Графический метод

📐 Основные формулы

1. Общий вид:

$$ a^{f(x)} \bowtie \sqrt{g(x)} $$

где ⋈ — один из знаков: >, <, ≥, ≤

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: 2x ≥ √x

Решение:

1. Найдём ОДЗ:

x ≥ 0

2. Рассмотрим функцию f(x) = 2x − √x

3. Проверим значения:

При x = 0: 2⁰ = 1, √0 = 0 ⇒ 1 > 0 ✓
При x = 1: 2¹ = 2, √1 = 1 ⇒ 2 > 1 ✓
При x = 4: 2⁴ = 16, √4 = 2 ⇒ 16 > 2 ✓

4. Показательная функция растёт быстрее корня:

2x ≥ √x для всех x ≥ 0
Ответ: [0; +∞)
