📊 Логарифмические неравенства

📚 Теория

Логарифмическое неравенство — неравенство, содержащее переменную под знаком логарифма.

⚠️ Важно! Всегда проверяйте ОДЗ: выражение под логарифмом > 0, основание > 0 и ≠ 1.
🔹 Основное свойство:
  • Если a > 1: logaf(x) > logag(x) ⇔ f(x) > g(x)
  • Если 0 < a < 1: logaf(x) > logag(x) ⇔ f(x) < g(x)

📐 Основные формулы

1. Неравенство вида logaf(x) > b:

$$ \log_a f(x) > b $$ $$ \begin{cases} f(x) > a^b, \text{ если } a > 1 \\ 0 < f(x) < a^b, \text{ если } 0 < a < 1 \end{cases} $$
2. Неравенство вида logaf(x) > logag(x):

$$ \log_a f(x) > \log_a g(x) $$ $$ \begin{cases} f(x) > g(x) > 0, \text{ если } a > 1 \\ 0 < f(x) < g(x), \text{ если } 0 < a < 1 \end{cases} $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: log₂(x + 3) > 2

Решение:

1. Найдём ОДЗ:

x + 3 > 0 ⇒ x > −3

2. Так как 2 > 1, знак сохраняется:

x + 3 > 2²
x + 3 > 4
x > 1

3. Пересечём с ОДЗ:

x ∈ (1; +∞)
Ответ: (1; +∞)

Пример 2: Решите неравенство: log1/2(x − 1) > −2

Решение:

1. Найдём ОДЗ:

x − 1 > 0 ⇒ x > 1

2. Так как 0 < 1/2 < 1, знак меняется:

x − 1 < (1/2)⁻²
x − 1 < 4
x < 5

3. Пересечём с ОДЗ:

x ∈ (1; 5)
Ответ: (1; 5)
