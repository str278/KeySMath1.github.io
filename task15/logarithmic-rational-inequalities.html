📊 Неравенства рациональные относительно логарифмической функции

📚 Теория

Неравенства, рациональные относительно логарифмической функции — неравенства, которые можно привести к виду рационального неравенства заменой переменной t = logax.

⚠️ Важно! Не забывайте про ОДЗ: x > 0
🔹 Алгоритм решения:
  1. Найти ОДЗ: x > 0
  2. Сделать замену t = logax
  3. Решить рациональное неравенство относительно t
  4. Вернуться к переменной x

📐 Основные формулы

1. Общая форма:

$$ R(\log_a x) \bowtie 0 $$

где R — рациональная функция

2. Замена переменной:

$$ t = \log_a x $$ $$ x = a^t, \quad x > 0 $$

💡 Примеры решения (ЕГЭ)

Пример 1: Решите неравенство: (log₂x)² − 3log₂x + 2 > 0

Решение:

1. Найдём ОДЗ:

x > 0

2. Сделаем замену:

t = log₂x

3. Получим квадратное неравенство:

t² − 3t + 2 > 0
(t−1)(t−2) > 0
t ∈ (−∞; 1) ∪ (2; +∞)

4. Вернёмся к x:

log₂x < 1 ⇒ x < 2
log₂x > 2 ⇒ x > 4

5. С учётом ОДЗ:

x ∈ (0; 2) ∪ (4; +∞)
Ответ: (0; 2) ∪ (4; +∞)
