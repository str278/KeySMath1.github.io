📈 Линейные функции

📚 Теория

Линейная функция — функция вида y = kx + b, где k и b — числа, x — независимая переменная (аргумент), y — зависимая переменная (функция).

🔹 Обозначения:
k — угловой коэффициент (коэффициент наклона)
b — свободный член (точка пересечения с осью Oy)
x — аргумент
y — функция
🔹 Основные свойства:
  • График — прямая линия
  • Область определения: D(y) = (−∞; +∞)
  • Область значений: E(y) = (−∞; +∞)
  • При k > 0 функция возрастает
  • При k < 0 функция убывает
  • При k = 0 функция постоянна: y = b

График линейной функции

k = tg α — угловой коэффициент
b — точка пересечения с осью Oy

📐 Основные формулы

1. Общая формула линейной функции:
$$ y = kx + b $$
2. Угловой коэффициент:
$$ k = \tan\alpha = \frac{y_2 - y_1}{x_2 - x_1} $$

где (x₁; y₁) и (x₂; y₂) — две точки на прямой

3. Точки пересечения с осями:
$$ \text{С осью Oy: } (0; b) $$ $$ \text{С осью Ox: } \left(-\frac{b}{k}; 0\right) $$
4. Уравнение прямой через две точки:
$$ \frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} $$

💡 Пример решения (ЕГЭ)

Условие: На рисунке изображён график функции y = kx + b. Найдите k, если график проходит через точки A(1; 3) и B(3; 7).

Решение:

1. Найдём угловой коэффициент k:

k = (y₂ − y₁) / (x₂ − x₁)
k = (7 − 3) / (3 − 1)
k = 4 / 2 = 2

2. Найдём b, подставив координаты точки A:

3 = 2 · 1 + b
b = 3 − 2 = 1
Ответ: k = 2, b = 1
