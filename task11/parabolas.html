📊 Параболы

📚 Теория

Квадратичная функция — функция вида y = ax² + bx + c, где a ≠ 0. График квадратичной функции — парабола.

🔹 Обозначения:
a — старший коэффициент
b — второй коэффициент
c — свободный член
D — дискриминант
(m; n) — вершина параболы
🔹 Основные свойства:
  • При a > 0 ветви параболы направлены вверх
  • При a < 0 ветви параболы направлены вниз
  • Вершина параболы: m = −b/(2a), n = f(m)
  • Ось симметрии: x = m
  • Точки пересечения с Ox: корни уравнения ax² + bx + c = 0

График квадратичной функции

📐 Основные формулы

1. Общая формула квадратичной функции:
$$ y = ax^2 + bx + c, \quad a \neq 0 $$
2. Координаты вершины параболы:
$$ m = -\frac{b}{2a}, \quad n = f(m) = c - \frac{b^2}{4a} $$
3. Дискриминант и корни:
$$ D = b^2 - 4ac $$ $$ x_{1,2} = \frac{-b \pm \sqrt{D}}{2a} $$
4. Канонический вид:
$$ y = a(x - m)^2 + n $$

💡 Пример решения (ЕГЭ)

Условие: Найдите вершину параболы y = 2x² − 8x + 5.

Решение:

1. Найдём абсциссу вершины:

m = −b/(2a) = −(−8)/(2·2) = 8/4 = 2

2. Найдём ординату вершины:

n = f(2) = 2·2² − 8·2 + 5
n = 8 − 16 + 5 = −3
Ответ: (2; −3)
