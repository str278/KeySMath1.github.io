📐 Тригонометрические функции

📚 Теория

Тригонометрические функции — функции, выражающие зависимость между углами и сторонами треугольника: синус, косинус, тангенс, котангенс.

🔹 Основные функции:
y = sin x — синус
y = cos x — косинус
y = tan x — тангенс
y = cot x — котангенс
🔹 Свойства y = sin x:
  • Область определения: D(y) = (−∞; +∞)
  • Область значений: E(y) = [−1; 1]
  • Период: T = 2π
  • Функция нечётная: sin(−x) = −sin x
🔹 Свойства y = cos x:
  • Область определения: D(y) = (−∞; +∞)
  • Область значений: E(y) = [−1; 1]
  • Период: T = 2π
  • Функция чётная: cos(−x) = cos x

Графики sin x и cos x

📐 Основные формулы

1. Общая формула синусоиды:
$$ y = A \sin(\omega x + \varphi) + b $$

где A — амплитуда, ω — угловая частота, φ — начальная фаза, b — сдвиг по вертикали

2. Период функции:
$$ T = \frac{2\pi}{\omega} $$
