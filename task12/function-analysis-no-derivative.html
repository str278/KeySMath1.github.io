📊 Исследование функций без производной

📚 Теория

Исследование без производной — нахождение наибольшего/наименьшего значения функции с использованием свойств функций, оценок и неравенств.

🔹 Основные методы:
Метод оценок — использование известных неравенств
Метод замены переменной — сведение к более простой функции
Свойства монотонности — использование возрастания/убывания
Неравенство Коши — для сумм и произведений
🔹 Полезные неравенства:
  • Неравенство Коши: (a + b)/2 ≥ √(ab) для a, b ≥ 0
  • Неравенство между средними: √((a² + b²)/2) ≥ (a + b)/2 ≥ √(ab)
  • Модуль: |a| ≥ a, |a| ≥ −a
  • Квадрат: a² ≥ 0 для любого a

📐 Основные методы

1. Метод выделения полного квадрата:
$$ ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \left(c - \frac{b^2}{4a}\right) $$

Наименьшее значение: c − b²/(4a) при a > 0

2. Неравенство Коши для двух чисел:
$$ \frac{a + b}{2} \geq \sqrt{ab}, \quad a, b \geq 0 $$

Равенство достигается при a = b

3. Оценка суммы:
$$ a + \frac{1}{a} \geq 2, \quad a > 0 $$

💡 Пример решения (ЕГЭ)

Условие: Найдите наименьшее значение функции y = x + 4/x на промежутке (0; +∞).

Решение:

1. Применим неравенство Коши:

x + 4/x ≥ 2√(x · 4/x) = 2√4 = 4

2. Равенство достигается при:

x = 4/x
x² = 4
x = 2 (т.к. x > 0)

3. Проверка:

y(2) = 2 + 4/2 = 2 + 2 = 4
Ответ: 4
