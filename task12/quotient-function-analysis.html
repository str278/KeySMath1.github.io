➗ Исследование частного функций

📚 Теория

Частное функций — функция вида y = f(x)/g(x). При исследовании важно правильно найти производную частного и учесть ОДЗ.

🔹 Основные понятия:
y = f(x)/g(x) — частное двух функций
(u/v)' = (u'v − uv')/v² — правило частного
g(x) ≠ 0 — условие ОДЗ
🔹 Особенности исследования:
  • Производная частного: (f/g)' = (f'g − fg')/g²
  • Обязательно учитывать ОДЗ: g(x) ≠ 0
  • Приравнивать числитель производной к нулю: f'g − fg' = 0
  • Проверять точки разрыва функции

📐 Основные формулы

1. Производная частного:
$$ \left(\frac{f(x)}{g(x)}\right)' = \frac{f'(x)g(x) - f(x)g'(x)}{g^2(x)} $$
2. Частные случаи:
$$ \left(\frac{1}{g(x)}\right)' = -\frac{g'(x)}{g^2(x)} $$ $$ \left(\frac{f(x)}{x}\right)' = \frac{f'(x) \cdot x - f(x)}{x^2} $$
3. Условие экстремума:
$$ f'(x)g(x) - f(x)g'(x) = 0 $$ $$ \frac{f'(x)}{f(x)} = \frac{g'(x)}{g(x)} \quad \text{(если f(x) ≠ 0, g(x) ≠ 0)} $$

💡 Пример решения (ЕГЭ)

Условие: Найдите точку минимума функции y = (x² + 144)/x на промежутке (0; +∞).

Решение:

1. Найдём производную:

y' = ((x² + 144)' · x − (x² + 144) · x')/x²
y' = (2x · x − (x² + 144) · 1)/x²
y' = (2x² − x² − 144)/x²
y' = (x² − 144)/x²

2. Найдём критические точки (y' = 0):

x² − 144 = 0
x² = 144
x = 12 или x = −12
x = 12 (т.к. x > 0)

3. Определим знак производной:

При 0 < x < 12: y' < 0 (функция убывает)
При x > 12: y' > 0 (функция возрастает)

4. Вывод:

x = 12 — точка минимума
Ответ: 12
