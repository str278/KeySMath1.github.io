📈 Исследование показательных и логарифмических функций

📚 Теория

Исследование функций — нахождение точек экстремума, наибольшего и наименьшего значения функции на промежутке.

🔹 Основные понятия:
Точка максимума — точка, в которой функция принимает наибольшее значение в некоторой окрестности
Точка минимума — точка, в которой функция принимает наименьшее значение в некоторой окрестности
Точки экстремума — точки максимума и минимума
Наибольшее/наименьшее значение — максимальное/минимальное значение на отрезке
🔹 Алгоритм исследования:
  • Найти производную функции
  • Найти критические точки (где f'(x) = 0 или не существует)
  • Определить знак производной на промежутках
  • Найти точки экстремума
  • Вычислить значения функции в точках экстремума и на концах отрезка

📐 Основные формулы

1. Производная показательной функции:
$$ (a^x)' = a^x \ln a $$ $$ (e^x)' = e^x $$
2. Производная логарифмической функции:
$$ (\log_a x)' = \frac{1}{x \ln a} $$ $$ (\ln x)' = \frac{1}{x} $$
3. Производная сложной функции:
$$ (f(g(x)))' = f'(g(x)) \cdot g'(x) $$

💡 Пример решения (ЕГЭ)

Условие: Найдите точку минимума функции y = (x − 3)eˣ⁻³.

Решение:

1. Найдём производную:

y' = (x − 3)' · eˣ⁻³ + (x − 3) · (eˣ⁻³)'
y' = 1 · eˣ⁻³ + (x − 3) · eˣ⁻³
y' = eˣ⁻³(1 + x − 3) = eˣ⁻³(x − 2)

2. Найдём критические точки (y' = 0):

eˣ⁻³(x − 2) = 0
x − 2 = 0 (т.к. eˣ⁻³ > 0 всегда)
x = 2

3. Определим знак производной:

При x < 2: y' < 0 (функция убывает)
При x > 2: y' > 0 (функция возрастает)

4. Вывод:

x = 2 — точка минимума
Ответ: 2
