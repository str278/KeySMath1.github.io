✖️ Исследование произведения функций

📚 Теория

Произведение функций — функция вида y = f(x) · g(x). При исследовании важно правильно найти производную произведения.

🔹 Основные понятия:
y = f(x) · g(x) — произведение двух функций
(uv)' = u'v + uv' — правило произведения
Критические точки — точки, где y' = 0 или не существует
🔹 Особенности исследования:
  • Производная произведения: (f·g)' = f'·g + f·g'
  • Часто удобно выносить общий множитель за скобки
  • Приравнивать производную к нулю: f'·g + f·g' = 0
  • Проверять точки, где одна из функций равна нулю

📐 Основные формулы

1. Производная произведения:
$$ (f(x) \cdot g(x))' = f'(x) \cdot g(x) + f(x) \cdot g'(x) $$
2. Частные случаи:
$$ (x \cdot f(x))' = f(x) + x \cdot f'(x) $$ $$ (e^x \cdot f(x))' = e^x \cdot f(x) + e^x \cdot f'(x) = e^x(f(x) + f'(x)) $$
3. Вынесение общего множителя:
$$ f'(x)g(x) + f(x)g'(x) = 0 $$ $$ f'(x)g(x) = -f(x)g'(x) $$ $$ \frac{f'(x)}{f(x)} = -\frac{g'(x)}{g(x)} \quad \text{(если f(x) ≠ 0, g(x) ≠ 0)} $$

💡 Пример решения (ЕГЭ)

Условие: Найдите точку максимума функции y = (x² − 9x + 9)eˣ.

Решение:

1. Найдём производную:

y' = (x² − 9x + 9)' · eˣ + (x² − 9x + 9) · (eˣ)'
y' = (2x − 9)eˣ + (x² − 9x + 9)eˣ
y' = eˣ(2x − 9 + x² − 9x + 9)
y' = eˣ(x² − 7x)
y' = eˣ · x(x − 7)

2. Найдём критические точки (y' = 0):

eˣ · x(x − 7) = 0
x = 0 или x = 7 (т.к. eˣ > 0 всегда)

3. Определим знак производной:

При x < 0: y' > 0 (функция возрастает)
При 0 < x < 7: y' < 0 (функция убывает)
При x > 7: y' > 0 (функция возрастает)

4. Вывод:

x = 0 — точка максимума
Ответ: 0
