📐 Исследование тригонометрических функций

📚 Теория

Тригонометрические функции — функции, содержащие sin x, cos x, tan x, cot x. При исследовании важно учитывать периодичность и ограниченность.

🔹 Основные понятия:
sin x, cos x — ограничены: −1 ≤ sin x, cos x ≤ 1
tan x, cot x — неограничены
Период — T = 2π для sin, cos; T = π для tan, cot
🔹 Особенности исследования:
  • Производные: (sin x)' = cos x, (cos x)' = −sin x
  • Учитывать периодичность при поиске экстремумов
  • sin²x + cos²x = 1 — основное тригонометрическое тождество
  • На отрезке проверять концы и критические точки

📐 Основные формулы

1. Производные тригонометрических функций:
$$ (\sin x)' = \cos x $$ $$ (\cos x)' = -\sin x $$ $$ (\tan x)' = \frac{1}{\cos^2 x} $$ $$ (\cot x)' = -\frac{1}{\sin^2 x} $$
2. Производная сложной функции:
$$ (\sin(f(x)))' = \cos(f(x)) \cdot f'(x) $$ $$ (\cos(f(x)))' = -\sin(f(x)) \cdot f'(x) $$
3. Основные тождества:
$$ \sin^2 x + \cos^2 x = 1 $$ $$ \tan x = \frac{\sin x}{\cos x}, \quad \cot x = \frac{\cos x}{\sin x} $$

💡 Пример решения (ЕГЭ)

Условие: Найдите наибольшее значение функции y = 3sin x − 4cos x.

Решение:

1. Найдём производную:

y' = 3cos x − 4(−sin x)
y' = 3cos x + 4sin x

2. Найдём критические точки (y' = 0):

3cos x + 4sin x = 0
4sin x = −3cos x
tan x = −3/4

3. Альтернативный метод — оценка:

Функцию можно представить в виде:

y = R sin(x − φ)
где R = √(3² + 4²) = √(9 + 16) = √25 = 5

4. Наибольшее значение синуса равно 1:

y_max = 5 · 1 = 5
Ответ: 5
