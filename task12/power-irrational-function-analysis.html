🔍 Исследование степенных и иррациональных функций

📚 Теория

Степенные функции — функции вида y = xⁿ. Иррациональные функции — функции, содержащие переменную под знаком корня.

🔹 Обозначения:
y = xⁿ — степенная функция
y = ⁿ√x — корень n-й степени
ОДЗ — область допустимых значений
🔹 Особенности исследования:
  • Важно учитывать ОДЗ (подкоренное выражение ≥ 0 для чётных корней)
  • Производная корня: (√x)' = 1/(2√x)
  • При исследовании на отрезке проверять концы отрезка и точки, где производная = 0

📐 Основные формулы

1. Производная степенной функции:
$$ (x^n)' = n x^{n-1} $$
2. Производная корня:
$$ (\sqrt{x})' = \frac{1}{2\sqrt{x}} $$ $$ (\sqrt[n]{x})' = \frac{1}{n} x^{\frac{1}{n}-1} $$
3. Производная сложной функции с корнем:
$$ (\sqrt{f(x)})' = \frac{f'(x)}{2\sqrt{f(x)}} $$

💡 Пример решения (ЕГЭ)

Условие: Найдите наибольшее значение функции y = √(−x² + 4x + 5) на отрезке [−1; 3].

Решение:

1. Найдём ОДЗ:

−x² + 4x + 5 ≥ 0
x² − 4x − 5 ≤ 0
(x − 5)(x + 1) ≤ 0
x ∈ [−1; 5]

2. Найдём производную:

y' = (−2x + 4)/(2√(−x² + 4x + 5))

3. Критические точки (y' = 0):

−2x + 4 = 0
x = 2

4. Вычислим значения на концах и в критической точке:

y(−1) = √(−1 − 4 + 5) = 0
y(2) = √(−4 + 8 + 5) = √9 = 3
y(3) = √(−9 + 12 + 5) = √8 ≈ 2.83
Ответ: 3
