🔢 Числа и их свойства (Задание 19)

📚 Основные понятия

В задании 19 часто проверяются знания о делимости целых чисел. Основные определения:

  • Делимость: Число a делится на число b (обозначается a ⋮ b), если существует целое k такое, что a = b · k.
  • Деление с остатком: a = bq + r, где 0 ≤ r < b.
  • НОД (Наибольший общий делитель): Наибольшее число, на которое делятся оба числа.
  • НОК (Наименьшее общее кратное): Наименьшее число, которое делится на оба числа.
  • Взаимно простые числа: Числа, у которых НОД равен 1.
Важное свойство:
a · b = НОД(a, b) · НОК(a, b)

🎯 Типичные методы решения

Метод 1: Разложение на множители

Если дано уравнение вида xy + ax + by = c, пытаемся сгруппировать слагаемые, чтобы получить произведение скобок.

xy + ax + by + ab = c + ab ⇒ (x + b)(y + a) = c + ab

Затем перебираем все делители числа c + ab.

Метод 2: Использование остатков

Анализ остатков при делении на 3, 4, 5 и т.д. помогает доказать невозможность равенства или найти свойства чисел.

Например: квадрат целого числа при делении на 3 может давать остаток только 0 или 1.

📝 Примеры решения

Пример 1. Уравнение в целых числах

Найдите все пары целых чисел (x, y), удовлетворяющие уравнению:

xy + 3x − 2y = 10
Решение:
1. Группировка:

Вынесем x за скобки в первых двух слагаемых:

x(y + 3) − 2y = 10

Чтобы выделить общий множитель (y+3), добавим и вычтем 2·3 = 6:

x(y + 3) − 2(y + 3) + 6 = 10
(x − 2)(y + 3) = 4
2. Перебор делителей:

Так как x и y целые, то (x−2) и (y+3) — целые делители числа 4.

Делители 4: ±1, ±2, ±4.

Составим все возможные пары множителей, произведение которых равно 4:

  1. x − 2 = 1, y + 3 = 4 ⇒ x = 3, y = 1
  2. x − 2 = 4, y + 3 = 1 ⇒ x = 6, y = −2
  3. x − 2 = 2, y + 3 = 2 ⇒ x = 4, y = −1
  4. x − 2 = −1, y + 3 = −4 ⇒ x = 1, y = −7
  5. x − 2 = −4, y + 3 = −1 ⇒ x = −2, y = −4
  6. x − 2 = −2, y + 3 = −2 ⇒ x = 0, y = −5

Ответ: (3; 1), (6; −2), (4; −1), (1; −7), (−2; −4), (0; −5)

Пример 2. Доказательство делимости

Докажите, что для любого натурального n число n³ − n делится на 6.

Доказательство:
1. Разложим выражение на множители:
n³ − n = n(n² − 1) = n(n − 1)(n + 1)

Получили произведение трех последовательных натуральных чисел: (n−1), n, (n+1).

2. Анализ делимости:

Среди любых двух последовательных чисел одно обязательно четное (делится на 2).

Среди любых трех последовательных чисел одно обязательно делится на 3.

3. Вывод:

Так как произведение делится и на 2, и на 3, и эти числа взаимно просты, то произведение делится на 2·3 = 6.

Что и требовалось доказать.

⚠️ Типичные ошибки:
• Забывают отрицательные делители при переборе вариантов.
• Не проверяют, являются ли найденные x и y целыми числами.
• Путают понятия "делится" и "делит" (a делится на b значит a/b целое).
• Забывают, что 1 не является простым числом.
