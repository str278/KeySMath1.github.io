📐 Длина и угол между векторами

📚 Теория

Длина вектора — расстояние между началом и концом вектора. Угол между векторами — угол, образованный векторами при их совмещении началами.

🔹 Обозначения:
|a⃗| — длина вектора a⃗
φ — угол между векторами
cos φ — косинус угла
🔹 Основные свойства:
  • Длина вектора всегда неотрицательна: |a⃗| ≥ 0
  • |a⃗| = 0 только для нулевого вектора
  • 0° ≤ φ ≤ 180°
  • Если φ = 0°, векторы сонаправлены
  • Если φ = 180°, векторы противоположно направлены
  • Если φ = 90°, векторы перпендикулярны

Длина и угол между векторами

|a⃗| и |b⃗| — длины векторов
φ — угол между векторами

📐 Основные формулы

1. Длина вектора по координатам:
$$ |\vec{a}| = \sqrt{x^2 + y^2} $$
2. Длина вектора по точкам:
$$ |\vec{AB}| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2} $$
3. Косинус угла между векторами:
$$ \cos\varphi = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| \cdot |\vec{b}|} = \frac{x_1 x_2 + y_1 y_2}{\sqrt{x_1^2 + y_1^2} \cdot \sqrt{x_2^2 + y_2^2}} $$

💡 Пример решения (ЕГЭ)

Условие: Даны векторы a⃗(3; 4) и b⃗(5; 0). Найдите косинус угла между ними.

Решение:

1. Найдём скалярное произведение:

a⃗ · b⃗ = 3 · 5 + 4 · 0 = 15

2. Найдём длины векторов:

|a⃗| = √(3² + 4²) = √(9 + 16) = √25 = 5
|b⃗| = √(5² + 0²) = √25 = 5

3. Найдём косинус угла:

cos φ = 15 / (5 · 5) = 15/25 = 0.6
Ответ: 0.6
