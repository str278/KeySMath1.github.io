📐 Угол между плоскостями

📚 Что такое угол между плоскостями?

Когда две плоскости пересекаются, между ними образуется двугранный угол. Чтобы его измерить, строят линейный угол: выбирают точку на линии пересечения, проводят в каждой плоскости перпендикуляр к этой линии, и угол между перпендикулярами будет искомым.

Рис. 1. Построение линейного угла между двумя пересекающимися плоскостями

Угол между плоскостями всегда лежит в диапазоне от 0° до 90°. Если плоскости параллельны — угол 0°. Если перпендикулярны — 90°.

🔧 Как находить угол на ЕГЭ?

В задании 14 обычно используют один из трёх подходов:

  • Геометрический: строят перпендикуляры к линии пересечения и находят угол в треугольнике.
  • Через нормали: находят векторы, перпендикулярные каждой плоскости, и вычисляют угол между ними.
  • Метод проекций: если известна площадь фигуры и её проекции, угол находится через отношение площадей.
Формула через нормали (простыми словами):
Косинус угла равен модулю скалярного произведения двух нормалей, делённому на произведение их длин.
На практике: перемножаем соответствующие координаты, складываем, берём модуль, делим на произведение длин векторов.

💡 Пример 1: Куб

Условие: В кубе ABCDA₁B₁C₁D₁ найдите угол между плоскостями A₁BD и B₁D₁C. Ребро куба равно 1.

Рис. 2. Куб с выделенными плоскостями A₁BD и B₁D₁C

Решение:

1. Вводим систему координат. Начало в точке A. Оси идут вдоль рёбер куба.
2. Находим нормали к плоскостям. Для A₁BD нормаль равна (1, 1, 1). Для B₁D₁C нормаль равна (-1, -1, -1).
3. Считаем скалярное произведение: 1·(-1) + 1·(-1) + 1·(-1) = -3. Модуль равен 3.
4. Длины нормалей: корень из 3 у каждой. Произведение длин = 3.
5. Косинус угла = 3 / 3 = 1. Угол = арккосинус от 1/3.
Ответ: arccos(1/3)

💡 Пример 2: Правильная пирамида

Условие: В правильной четырёхугольной пирамиде SABCD сторона основания равна 4, боковое ребро равно 6. Найдите угол между гранью SAB и основанием.

Рис. 3. Пирамида с построенным линейным углом α между гранью и основанием

Решение:

1. Проводим высоту пирамиды SO. Из центра основания O опускаем перпендикуляр OK на сторону AB.
2. По теореме о трёх перпендикулярах SK тоже перпендикулярен AB. Значит, угол SKO — искомый.
3. OK равен половине стороны основания: 2. Диагональ основания = 4√2, половина = 2√2.
4. Из треугольника SOA находим высоту SO = корень из (36 - 8) = 2√7.
5. Тангенс угла α = SO / OK = 2√7 / 2 = √7.
Ответ: arctan(√7)

💡 Пример 3: Треугольная призма

Условие: В правильной треугольной призме ABCA₁B₁C₁ сторона основания равна 2, высота равна √3. Найдите угол между плоскостями AB₁C₁ и A₁BC.

Рис. 4. Призма с пересекающимися плоскостями AB₁C₁ и A₁BC

Решение:

1. Вводим координаты. A(0,0,0), B(2,0,0), C(1,√3,0). Верхние точки имеют z = √3.
2. Находим нормаль к AB₁C₁: векторы AB₁(2,0,√3) и AC₁(1,√3,√3). Их векторное произведение даёт (-3, -√3, 2√3).
3. Находим нормаль к A₁BC: векторы A₁B(2,0,-√3) и A₁C(1,√3,-√3). Векторное произведение даёт (3, √3, 2√3).
4. Скалярное произведение нормалей: (-3)·3 + (-√3)·√3 + (2√3)·(2√3) = -9 - 3 + 12 = 0.
5. Если скалярное произведение равно нулю, векторы перпендикулярны. Значит, плоскости перпендикулярны.
Ответ: 90°

📝 Советы для экзамена

  • Всегда начинайте с чертежа. Отмечайте линию пересечения и перпендикуляры.
  • Координатный метод спасает, когда сложно увидеть геометрию. Главное — аккуратно считать векторное произведение.
  • Проверяйте ответ: угол между плоскостями не может быть тупым. Если косинус отрицательный, берите модуль.
  • В бланке пишите ответ в виде аркфункции или градусов, как требуется в условии.
