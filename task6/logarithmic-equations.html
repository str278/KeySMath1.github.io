📐 Логарифмические уравнения

📚 Теория

Логарифмическое уравнение — уравнение, в котором переменная содержится под знаком логарифма.

🔹 Основные понятия:
log_a(x) — логарифм по основанию a
a > 0, a ≠ 1 — основание логарифма
x > 0 — аргумент логарифма (ОДЗ)
🔹 Основные методы решения:
  • Уравнивание оснований — приведение к одному основанию
  • Потенцирование — переход от логарифмов к степеням
  • Замена переменной — введение новой переменной
  • Свойства логарифмов — упрощение выражений

📐 Основные формулы

1. Простейшее логарифмическое уравнение:
$$ \log_a x = b \quad \Leftrightarrow \quad x = a^b $$

где a > 0, a ≠ 1, x > 0

2. Уравнивание логарифмов:
$$ \log_a f(x) = \log_a g(x) \quad \Leftrightarrow \quad \begin{cases} f(x) = g(x) \\ f(x) > 0 \\ g(x) > 0 \end{cases} $$
3. Основные свойства логарифмов:
$$ \log_a(xy) = \log_a x + \log_a y $$ $$ \log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y $$ $$ \log_a(x^n) = n \log_a x $$ $$ \log_a a = 1, \quad \log_a 1 = 0 $$

💡 Пример решения (ЕГЭ)

Условие: Решите уравнение: log₂(x + 3) = 3

Решение:

1. Найдём ОДЗ:

x + 3 > 0 ⇒ x > −3

2. Перейдём от логарифмического уравнения к показательному:

x + 3 = 2³
x + 3 = 8

3. Найдём x:

x = 8 − 3 = 5

4. Проверка на ОДЗ:

5 > −3 ✓
Ответ: 5
