📐 Рациональные уравнения

📚 Теория

Рациональное уравнение — уравнение вида P(x)/Q(x) = 0, где P(x) и Q(x) — многочлены.

🔹 Основные понятия:
ОДЗ — область допустимых значений (знаменатель ≠ 0)
P(x) = 0 — числитель
Q(x) ≠ 0 — знаменатель
🔹 Алгоритм решения:
  • Найти ОДЗ (знаменатель ≠ 0)
  • Приравнять числитель к нулю
  • Решить полученное уравнение
  • Проверить корни на принадлежность ОДЗ

📐 Основные формулы

1. Рациональное уравнение:
$$ \frac{P(x)}{Q(x)} = 0 \quad \Leftrightarrow \quad \begin{cases} P(x) = 0 \\ Q(x) \neq 0 \end{cases} $$
2. Приведение к общему знаменателю:
$$ \frac{A}{B} = \frac{C}{D} \quad \Rightarrow \quad A \cdot D = B \cdot C $$
3. Разложение на множители:
$$ \frac{(x-a)(x-b)}{(x-c)(x-d)} = 0 \quad \Rightarrow \quad x = a \text{ или } x = b $$

при условии x ≠ c и x ≠ d

💡 Пример решения (ЕГЭ)

Условие: Решите уравнение: (x² − 4)/(x − 2) = 0

Решение:

1. Найдём ОДЗ:

x − 2 ≠ 0 ⇒ x ≠ 2

2. Приравняем числитель к нулю:

x² − 4 = 0
(x − 2)(x + 2) = 0
x₁ = 2, x₂ = −2

3. Проверка на ОДЗ:

x = 2 — не подходит (не входит в ОДЗ)
x = −2 — подходит
Ответ: −2
