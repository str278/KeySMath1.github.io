📐 Линейные, квадратные, кубические уравнения

📚 Теория

Алгебраические уравнения — уравнения вида P(x) = 0, где P(x) — многочлен.

🔹 Виды уравнений:
Линейное: ax + b = 0
Квадратное: ax² + bx + c = 0
Кубическое: ax³ + bx² + cx + d = 0
🔹 Основные методы решения:
  • Линейные: перенос слагаемых, деление на коэффициент
  • Квадратные: дискриминант, теорема Виета, выделение полного квадрата
  • Кубические: разложение на множители, подбор корня, схема Горнера

📐 Основные формулы

1. Линейное уравнение:
$$ ax + b = 0 \quad \Rightarrow \quad x = -\frac{b}{a} $$
2. Квадратное уравнение (через дискриминант):
$$ ax^2 + bx + c = 0 $$ $$ D = b^2 - 4ac $$ $$ x_{1,2} = \frac{-b \pm \sqrt{D}}{2a} $$
3. Теорема Виета (для x² + px + q = 0):
$$ x_1 + x_2 = -p, \quad x_1 \cdot x_2 = q $$
4. Разложение квадратного трёхчлена:
$$ ax^2 + bx + c = a(x - x_1)(x - x_2) $$

💡 Пример решения (ЕГЭ)

Условие: Решите уравнение: x² − 5x + 6 = 0

Решение:

Способ 1 (через дискриминант):

D = (−5)² − 4 · 1 · 6 = 25 − 24 = 1
x₁ = (5 + 1)/2 = 3
x₂ = (5 − 1)/2 = 2

Способ 2 (теорема Виета):

Ищем два числа с суммой 5 и произведением 6
x₁ = 2, x₂ = 3
Ответ: 2; 3
