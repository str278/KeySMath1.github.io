📐 Иррациональные уравнения

📚 Теория

Иррациональное уравнение — уравнение, содержащее переменную под знаком корня.

🔹 Основные понятия:
ОДЗ — подкоренное выражение ≥ 0
Возведение в степень — основной метод решения
Проверка — обязательный этап
🔹 Алгоритм решения:
  • Найти ОДЗ (подкоренное выражение ≥ 0)
  • Возвести обе части в степень (обычно в квадрат)
  • Решить полученное уравнение
  • Проверить корни подстановкой в исходное уравнение

📐 Основные формулы

1. Простейшее иррациональное уравнение:
$$ \sqrt{f(x)} = a \quad \Leftrightarrow \quad \begin{cases} f(x) = a^2 \\ a \geq 0 \end{cases} $$
2. Уравнение вида √f(x) = √g(x):
$$ \sqrt{f(x)} = \sqrt{g(x)} \quad \Leftrightarrow \quad \begin{cases} f(x) = g(x) \\ f(x) \geq 0 \text{ или } g(x) \geq 0 \end{cases} $$
3. Уравнение вида √f(x) = g(x):
$$ \sqrt{f(x)} = g(x) \quad \Leftrightarrow \quad \begin{cases} f(x) = g^2(x) \\ g(x) \geq 0 \end{cases} $$

💡 Пример решения (ЕГЭ)

Условие: Решите уравнение: √(x + 3) = x − 3

Решение:

1. Найдём ОДЗ:

x + 3 ≥ 0 ⇒ x ≥ −3
x − 3 ≥ 0 ⇒ x ≥ 3
ОДЗ: x ≥ 3

2. Возведём обе части в квадрат:

x + 3 = (x − 3)²
x + 3 = x² − 6x + 9
x² − 7x + 6 = 0

3. Решим квадратное уравнение:

D = 49 − 24 = 25
x₁ = (7 + 5)/2 = 6
x₂ = (7 − 5)/2 = 1

4. Проверка на ОДЗ и подстановка:

x = 6: √(6 + 3) = √9 = 3, 6 − 3 = 3 ✓
x = 1: не входит в ОДЗ (1 < 3) ✗
Ответ: 6
